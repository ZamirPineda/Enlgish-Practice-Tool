Guia_Ejecucion_Nginx

Explicación

Esta configuración desplegará una instancia básica de Nginx, un servidor web de alto rendimiento y proxy inverso. Utilizaremos la imagen oficial de Nginx de Docker Hub y montaremos una configuración personalizada (nginx.conf) junto con un directorio que contendrá una página HTML estática (html/index.html).

Pasos:

1. Asegúrate de tener un directorio donde guardar nginx.conf y el directorio html con index.html.

2. Crea el archivo nginx.conf y el directorio html con su index.html en tu directorio de trabajo.

3. Ejecuta el comando podman run (o docker run) proporcionado en el mismo directorio donde creaste los archivos.

4. Una vez que el contenedor esté en ejecución, podrás acceder a la página web en http://localhost:8080 en tu navegador.

5. Para detener el contenedor: podman stop my-nginx (o docker stop my-nginx).

6. Para eliminar el contenedor: podman rm my-nginx (o docker rm my-nginx).

Comandos de Ejecución

podman run --name my-nginx -p 8080:80 -v ./nginx.conf:/etc/nginx/nginx.conf:ro -v ./html:/usr/share/nginx/html:ro -d nginx:latest

Archivos de Configuración

nginx.conf

user  nginx;
worker_processes  auto;

error_log  /var/log/nginx/error.log warn;
pid        /var/run/nginx.pid;

events {
    worker_connections  1024;
}

http {
    include       /etc/nginx/mime.types;
    default_type  application/octet-stream;

    log_format  main  '$remote_addr - $remote_user [$time_local] "$request" '
                      '$status $body_bytes_sent "$http_referer" '
                      '"$http_user_agent" "$http_x_forwarded_for"';

    access_log  /var/log/nginx/access.log  main;

    sendfile        on;
    #tcp_nopush     on;

    keepalive_timeout  65;

    #gzip  on;

    server {
        listen 80;
        server_name  localhost;

        location / {
            root   /usr/share/nginx/html;
            index  index.html index.htm;
        }

        error_page   500 502 503 504  /50x.html;
        location = /50x.html {
            root   /usr/share/nginx/html;
        }
    }
}

html/index.html

<!DOCTYPE html>
<html>
<head>
    <title>¡Hola Nginx!</title>
    <style>
        body { font-family: Arial, sans-serif; text-align: center; margin-top: 50px; }
        h1 { color: #333; }
        p { color: #666; }
    </style>
</head>
<body>
    <h1>¡Bienvenido a Nginx!</h1>
    <p>¡Tu servidor Nginx está funcionando correctamente en Podman/Docker!</p>
</body>
</html>
