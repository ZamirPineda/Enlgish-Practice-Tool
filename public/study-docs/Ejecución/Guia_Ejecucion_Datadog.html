Guia_Ejecucion_Datadog

Explicación

Esta configuración proporciona una instancia básica de Datadog Agent junto con una aplicación Flask de ejemplo, lo que permite observar cómo el agente recopila métricas, logs y trazas de una aplicación y las envía a Datadog HQ. Deberás reemplazar YOUR_DATADOG_API_KEY con tu clave API real de Datadog y datadoghq.com con el sitio de Datadog correcto (ej., eu.datadoghq.com). La aplicación Flask incluye la biblioteca ddtrace para instrumentación automática de APM y envía métricas personalizadas vía DogStatsD.

Pasos a seguir:

1. Guarda los archivos: Crea una carpeta y guarda docker-compose.yml, Dockerfile.app, app.py y requirements.txt en ella.

2. Obtén tu API Key de Datadog: Visita [Datadog](https://app.datadoghq.com/account/settings#api) para obtener tu clave API.

3. Actualiza docker-compose.yml: Reemplaza YOUR_DATADOG_API_KEY con tu clave API.

4. Ejecuta los contenedores: Abre una terminal en la carpeta donde guardaste los archivos y ejecuta el comando en runCommands.

5. Verifica en Datadog: Después de unos minutos, deberías ver métricas, logs y trazas de la aplicación my-flask-app en tu cuenta de Datadog.

Comandos de Ejecución

docker-compose up -d

Archivos de Configuración

Dockerfile.app

FROM python:3.9-slim-buster

# Establece el directorio de trabajo dentro del contenedor
WORKDIR /app

# Copia el archivo de requisitos e instala las dependencias
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# Copia la aplicación Flask
COPY app.py .

# Expone el puerto que usará la aplicación
EXPOSE 5000

# Comando para ejecutar la aplicación
CMD ["python", "app.py"]

docker-compose.yml

version: '3.8'
services:
  flask-app:
    build:
      context: .
      dockerfile: Dockerfile.app
    container_name: flask-app
    ports:
      - "5000:5000"
    environment:
      - FLASK_APP=app.py
      - FLASK_RUN_HOST=0.0.0.0
      # Configuración de ddtrace para APM y métricas personalizadas
      - DD_AGENT_HOST=datadog-agent
      - DD_TRACE_AGENT_HOSTNAME=datadog-agent
      - DD_SERVICE=my-flask-app
      - DD_ENV=local
      - DD_VERSION=1.0.0
      - DD_LOGS_INJECTION=true
    # Labels para la autodetección de Datadog (logs y http_check)
    labels:
      com.datadoghq.ad.logs: '[{"source": "flask", "service": "my-flask-app"}]'
      com.datadoghq.ad.check_names: '["http_check"]'
      com.datadoghq.ad.init_configs: '[{}]'
      com.datadoghq.ad.instances: '[{"url": "http://%%host%%:5000", "timeout": 1, "name": "my-flask-service", "tags": ["env:local"]}]'
    depends_on:
      - datadog-agent

  datadog-agent:
    image: datadog/agent:latest
    hostname: datadog-agent
    environment:
      - DD_API_KEY=YOUR_DATADOG_API_KEY
      - DD_SITE=datadoghq.com
      - DD_LOGS_ENABLED=true
      - DD_LOGS_CONFIG_CONTAINER_COLLECT_ALL=true
      - DD_PROCESS_AGENT_ENABLED=true
      - DD_APM_ENABLED=true
      - DD_APM_NON_LOCAL_TRAFFIC=true
      - DD_TAGS=env:local,project:datadog-guide
    ports:
      - "8125:8125/udp" # Para DogStatsD
      - "8126:8126/tcp" # Para APM
    volumes:
      # Permite al agente recolectar métricas del host y logs de contenedores
      - /var/run/docker.sock:/var/run/docker.sock:ro  # Usar /run/podman/podman.sock para Podman
      - /proc/:/host/proc/:ro
      - /sys/fs/cgroup:/host/sys/fs/cgroup:ro
    privileged: true # Necesario para monitorear el host completamente
    cap_add:
      - SYS_ADMIN # Permite al agente ejecutar algunas verificaciones de host
    networks:
      - default

networks:
  default:
    driver: bridge

app.py

import os
import logging
from flask import Flask, request, jsonify
from ddtrace import tracer
from datadog import DogStatsd
import time

# Configuración de logging
logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)

# Inicializa Flask
app = Flask(__name__)

# Inicializa DogStatsd para métricas personalizadas
statsd = DogStatsd(host=os.getenv('DD_AGENT_HOST', 'localhost'), port=8125)

# Decorador para trazas de Datadog APM
@tracer.wrap()
def do_some_work():
    time.sleep(0.05) # Simula algo de trabajo
    logger.info("Realizando alguna tarea importante...")
    statsd.increment('my_flask_app.work_done', tags=['result:success'])

@app.route('/')
def hello_world():
    logger.info("Solicitud recibida en el endpoint /")
    statsd.increment('my_flask_app.requests.total', tags=['endpoint:/'])
    with tracer.trace("web.request", service="my-flask-app") as span:
        span.set_tag("http.method", request.method)
        span.set_tag("http.url", request.url)
        do_some_work()
        statsd.histogram('my_flask_app.response_time', time.time() - span.start, tags=['endpoint:/'])
        return 'Hello, Datadog! From Flask app!'

@app.route('/metrics')
def metrics_endpoint():
    logger.warning("Solicitud a endpoint de métricas. Esto podría ser un problema si no está monitorizado correctamente.")
    statsd.increment('my_flask_app.requests.total', tags=['endpoint:/metrics'])
    statsd.gauge('my_flask_app.current_users', 10, tags=['region:us-east'])
    return jsonify({"status": "ok", "message": "Metrics exposed (simulated)"})

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000)
