Guia_Ejecucion_Jaeger

Explicación

Este JSON proporciona una guía sencilla para levantar una instancia de Jaeger "all-in-one" usando Podman o Docker. La imagen jaegertracing/all-in-one incluye todos los componentes necesarios (agente, colector, consulta y UI) en un solo contenedor, lo que es ideal para desarrollo local y pruebas. Se expondrán los puertos necesarios para enviar trazas y acceder a la interfaz de usuario.

Pasos a seguir:

1. Asegúrate de tener Docker o Podman instalado y funcionando.

2. Ejecuta el comando proporcionado en runCommands en tu terminal. Este comando descargará la imagen de Jaeger (si no la tienes ya) y la iniciará, mapeando los puertos esenciales.

3. Una vez que el contenedor esté corriendo, podrás acceder a la interfaz de usuario de Jaeger abriendo tu navegador en http://localhost:16686.

4. Tu aplicación podrá enviar trazas al colector de Jaeger en los puertos 6831 (UDP Thrift compact), 6832 (UDP Thrift binary) o 14268 (HTTP Thrift) en localhost.

Comandos de Ejecución

podman run -d --name jaeger -e COLLECTOR_ZIPKIN_HOST_PORT=:9411 -p 6831:6831/udp -p 6832:6832/udp -p 14268:14268 -p 16686:16686 jaegertracing/all-in-one:latest
