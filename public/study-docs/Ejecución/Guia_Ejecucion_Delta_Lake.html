Guia_Ejecucion_Delta Lake

Explicación

Esta guía le permitirá configurar una instancia local básica de Delta Lake utilizando Apache Spark y JupyterLab, orquestada con docker-compose. La configuración incluye:

  • Spark Master: El nodo principal de Apache Spark que coordina el clúster.
  • Spark Worker: Un nodo trabajador de Spark que ejecuta tareas computacionales.
  • JupyterLab con PySpark y Delta Lake: Un entorno interactivo de desarrollo donde podrá escribir y ejecutar código Python (PySpark) para interactuar con Delta Lake. Este servicio se construirá a partir de un Dockerfile personalizado que añade las librerías delta-spark y jupyterlab a una imagen base de Spark.

La persistencia de los datos de Delta Lake se gestionará mediante un volumen de Docker (delta_lake_data) compartido entre los servicios, asegurando que sus tablas Delta Lake no se pierdan al reiniciar los contenedores.

Pasos para ejecutar:

1. Cree la estructura de archivos: Cree un directorio para su proyecto (ej. delta-lake-local) y dentro de él, cree una carpeta llamada notebooks para almacenar sus cuadernos de Jupyter. Asegúrese de que docker-compose.yml y Dockerfile.spark-delta estén en el directorio raíz del proyecto.

    mkdir delta-lake-local
    cd delta-lake-local
    mkdir notebooks
    # Cree los archivos docker-compose.yml y Dockerfile.spark-delta aquí

2. Ejecute los contenedores: Abra una terminal en el directorio delta-lake-local y ejecute el comando proporcionado en runCommands.

3. Acceda a JupyterLab: Una vez que los contenedores estén en funcionamiento, acceda a JupyterLab abriendo su navegador web y navegando a http://localhost:8888.

4. Pruebe Delta Lake: Dentro de JupyterLab, cree un nuevo Python 3 (PySpark) notebook y pegue el siguiente código para probar la funcionalidad de Delta Lake:

    from pyspark.sql import SparkSession
    from delta.tables import *

    # Inicializa la sesión de Spark con soporte para Delta Lake
    spark = SparkSession.builder \
        .appName("DeltaLakeQuickstart") \
        .config("spark.sql.extensions", "io.delta.sql.DeltaSparkSessionExtension") \
        .config("spark.sql.catalog.spark_catalog", "org.apache.spark.sql.delta.catalog.DeltaCatalog") \
        .getOrCreate()

    print("Spark Session with Delta Lake support created successfully!")

    # Define una ruta para la tabla Delta Lake (dentro del volumen persistente)
    delta_table_path = "file:///opt/spark/work-dir/delta_lake_data/my_delta_table"

    # 1. Crea una tabla Delta Lake
    data = spark.createDataFrame([
        (1, "Alice", 30),
        (2, "Bob", 35),
        (3, "Charlie", 25)
    ], ["id", "name", "age"])

    data.write.format("delta").mode("overwrite").save(delta_table_path)
    print(f"Delta table created at {delta_table_path}")

    # 2. Lee de la tabla Delta Lake
    df = spark.read.format("delta").load(delta_table_path)
    print("Data from Delta table:")
    df.show()

    # 3. Realiza una actualización (ejemplo: cambia la edad de Alice)
    deltaTable = DeltaTable.forPath(spark, delta_table_path)
    deltaTable.update(
        condition="id = 1",
        set={"age": "31"}
    )
    print("Updated Alice's age.")

    # 4. Lee de nuevo para verificar la actualización
    df_updated = spark.read.format("delta").load(delta_table_path)
    print("Data after update:")
    df_updated.show()

    # 5. Accede a versiones históricas (Time Travel)
    df_version_0 = spark.read.format("delta").option("versionAsOf", 0).load(delta_table_path)
    print("Data from version 0 (before update):")
    df_version_0.show()

    spark.stop()
    print("Spark Session stopped.")

Para detener y limpiar los contenedores, use docker-compose down en el mismo directorio.

Comandos de Ejecución

docker-compose up -d

Archivos de Configuración

Dockerfile.spark-delta

# Usa una imagen base de Spark que incluya Python y Java.
FROM apache/spark:3.5.0-java17

# Cambia a usuario root para instalar dependencias del sistema
USER root

# Actualiza la lista de paquetes e instala pip para Python 3
RUN apt-get update && apt-get install -y --no-install-recommends \
    python3-pip \
    && rm -rf /var/lib/apt/lists/*

# Instala jupyterlab y la librería delta-spark
# delta-spark incluye la funcionalidad para interactuar con Delta Lake
RUN pip install --no-cache-dir jupyterlab==3.6.5 delta-spark==2.4.0

# Cambia de nuevo al usuario spark por defecto para ejecutar aplicaciones
USER spark

# Expone el puerto por defecto de JupyterLab
EXPOSE 8888

# Comando por defecto para JupyterLab.
# Este comando será sobrescrito por docker-compose.yml para añadir la configuración de Spark.
# --NotebookApp.token='' --NotebookApp.password='' permite el acceso sin token/contraseña, adecuado para desarrollo local.
CMD ["jupyter", "lab", "--ip=0.0.0.0", "--port=8888", "--allow-root", "--no-browser", "--NotebookApp.token=''", "--NotebookApp.password=''"]

docker-compose.yml

version: '3.8'

services:
  spark-master:
    image: apache/spark:3.5.0-java17
    container_name: spark-master
    # Inicia el nodo maestro de Spark
    command: bin/spark-class org.apache.spark.deploy.master.Master -h spark-master
    ports:
      - "8080:8080" # Interfaz de usuario del Spark Master
      - "7077:7077" # Puerto RPC del Spark Master
    environment:
      - SPARK_LOCAL_IP=spark-master
    volumes:
      # Monta un volumen para que los datos de Delta Lake persistan y sean accesibles
      - delta_lake_data:/opt/spark/work-dir/delta_lake_data

  spark-worker:
    image: apache/spark:3.5.0-java17
    container_name: spark-worker
    # Conecta el worker al Spark Master
    command: bin/spark-class org.apache.spark.deploy.worker.Worker spark://spark-master:7077
    ports:
      - "8081:8081" # Interfaz de usuario del Spark Worker
    environment:
      - SPARK_MASTER_URL=spark://spark-master:7077
      - SPARK_WORKER_CORES=1 # Número de núcleos de CPU para el worker
      - SPARK_WORKER_MEMORY=1G # Cantidad de memoria RAM para el worker
    volumes:
      # Comparte el mismo volumen de datos con el master para consistencia
      - delta_lake_data:/opt/spark/work-dir/delta_lake_data
    depends_on:
      - spark-master # Asegura que el master se inicie antes que el worker

  jupyterlab:
    build:
      context: .
      dockerfile: Dockerfile.spark-delta # Usa el Dockerfile personalizado
    container_name: jupyterlab
    ports:
      - "8888:8888" # Puerto para acceder a la interfaz de JupyterLab
    environment:
      - SPARK_MASTER_URL=spark://spark-master:7077
      - JUPYTER_ENABLE_LAB=yes # Habilita JupyterLab en lugar de solo Jupyter Notebook
      # Configuración crucial para PySpark con Delta Lake:
      # --packages: Descarga el paquete Delta Lake (io.delta:delta-core_2.12:2.4.0 para Spark 3.5.0/Scala 2.12)
      # --conf spark.sql.extensions: Registra la extensión de Delta SparkSession
      # --conf spark.sql.catalog.spark_catalog: Configura el catálogo de Spark para usar el catálogo de Delta
      - PYSPARK_SUBMIT_ARGS=--packages io.delta:delta-core_2.12:2.4.0 --conf "spark.sql.extensions=io.delta.sql.DeltaSparkSessionExtension" --conf "spark.sql.catalog.spark_catalog=org.apache.spark.sql.delta.catalog.DeltaCatalog" pyspark-shell
      - DELTA_LAKE_PATH=/opt/spark/work-dir/delta_lake_data # Ruta interna para los datos de Delta Lake
    volumes:
      - ./notebooks:/home/spark/notebooks # Monta un volumen para guardar sus notebooks
      - delta_lake_data:/opt/spark/work-dir/delta_lake_data # Acceso a los datos persistentes de Delta Lake
    depends_on:
      - spark-master # Asegura que el master se inicie antes que JupyterLab

volumes:
  delta_lake_data: # Define un volumen para la persistencia de los datos de Delta Lake
