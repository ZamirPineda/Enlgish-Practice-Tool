Guia_Ejecucion_Prometheus

Explicación

Esta guía le permitirá levantar una instancia básica de Prometheus localmente usando Podman o Docker. Se construirá una imagen de contenedor personalizada que incluirá un archivo de configuración mínimo (prometheus.yml). Esta configuración instruye a Prometheus para que se monitoree a sí mismo, exponiendo su interfaz web y métricas en el puerto 9090 de su máquina local. Una vez iniciado, podrá acceder a la UI de Prometheus en http://localhost:9090.

Comandos de Ejecución

podman build -t my-prometheus . && podman run -d -p 9090:9090 --name prometheus-instance my-prometheus

Archivos de Configuración

Dockerfile

# Usa la imagen oficial de Prometheus como base. Puedes especificar una versión específica, por ejemplo, prom/prometheus:v2.47.1
FROM prom/prometheus:latest

# Copia el archivo de configuración de Prometheus en el directorio de configuración del contenedor.
# Asegúrate de que 'prometheus.yml' esté en el mismo directorio que este Dockerfile.
COPY prometheus.yml /etc/prometheus/prometheus.yml

# Expone el puerto por defecto de Prometheus para que sea accesible desde fuera del contenedor.
EXPOSE 9090

# Define el comando de inicio para Prometheus, apuntando a nuestro archivo de configuración.
# También especificamos una ruta para el almacenamiento de TSDB (Time Series Database).
CMD ["--config.file=/etc/prometheus/prometheus.yml", "--storage.tsdb.path=/prometheus"]

prometheus.yml

global:
  # Establece el intervalo global en el que Prometheus intentará extraer métricas de sus objetivos.
  scrape_interval: 15s 
  # Etiquetas opcionales que se adjuntarán a todas las series temporales de este Prometheus.
  external_labels:
    monitor: 'local-prometheus'

# Lista de configuraciones de scraping.
scrape_configs:
  # Un 'job' representa una colección de objetivos que se tratan como un grupo lógico.
  - job_name: 'prometheus'
    # Configuración estática para los objetivos de este job.
    # Aquí, Prometheus se configurará para extraer métricas de sí mismo.
    static_configs:
      - targets: ['localhost:9090'] # El propio Prometheus expone sus métricas en este puerto por defecto.
