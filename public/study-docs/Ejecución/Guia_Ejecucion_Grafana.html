Guia_Ejecucion_Grafana

Explicación

Esta guía le permitirá iniciar una instancia básica de Grafana localmente utilizando Docker o Podman. Configuraremos Grafana para que se ejecute en el puerto 3000 de su máquina local y utilizaremos un volumen persistente para almacenar los datos de configuración, paneles y fuentes de datos. Esto asegura que sus datos no se pierdan si el contenedor se detiene o se elimina.

Pasos a seguir:

1. Crear un volumen (opcional pero recomendado): Aunque Docker/Podman puede crear el volumen automáticamente, es buena práctica crearlo explícitamente.

docker volume create grafana-storage

2. Ejecutar el contenedor de Grafana: El comando runCommands proporcionado a continuación iniciará el contenedor, mapeará el puerto y montará el volumen.

3. Acceder a Grafana: Una vez que el contenedor esté en funcionamiento, podrá acceder a la interfaz web de Grafana abriendo su navegador en http://localhost:3000.

4. Credenciales iniciales: Las credenciales predeterminadas para iniciar sesión son admin como usuario y admin como contraseña. Se le pedirá que cambie la contraseña en el primer inicio de sesión.

Comandos de Ejecución

docker run -d --name grafana -p 3000:3000 -v grafana-storage:/var/lib/grafana grafana/grafana
