Guia_Ejecucion_Cassandra

Explicación

Esta guía te permitirá levantar una instancia básica de Cassandra como un nodo único utilizando la imagen oficial de Docker (o Podman). Configura el puerto 9042 para la interfaz CQL y persiste los datos en un volumen para asegurar que la información no se pierda al reiniciar el contenedor. Es ideal para desarrollo local y pruebas básicas.

Comandos de Ejecución

docker run --name cassandra-node -p 9042:9042 -v cassandra_data:/var/lib/cassandra -d cassandra:latest
