Guia_Ejecucion_Apache Pulsar

Explicación

Esta guía te permitirá levantar una instancia básica de Apache Pulsar en modo standalone usando Podman o Docker. En este modo, un solo contenedor ejecuta todos los componentes necesarios de Pulsar (Zookeeper, BookKeeper y el Broker de Pulsar), lo que lo hace ideal para el desarrollo local y pruebas.

Los pasos son los siguientes:

1. Guardar el comando: Copia el comando docker run proporcionado.

2. Ejecutar el contenedor: Ejecuta el comando en tu terminal. Esto descargará la imagen de Apache Pulsar si no la tienes localmente y luego iniciará el contenedor en segundo plano.

3. Verificar el estado: Una vez que el contenedor esté en ejecución, Pulsar estará disponible en los puertos 6650 (para clientes) y 8080 (para la API de administración). Puedes verificar que el servicio está funcionando accediendo a http://localhost:8080/metrics en tu navegador, lo que debería mostrar métricas de Prometheus.

Para interactuar con Pulsar, puedes usar la herramienta de línea de comandos pulsar-client que se encuentra dentro del contenedor, o cualquier cliente Pulsar SDK desde tu aplicación.

Ejemplo de uso (dentro del contenedor):

docker exec -it pulsar-standalone bin/pulsar-admin clusters list

Comandos de Ejecución

docker run -d \
  -p 6650:6650 \
  -p 8080:8080 \
  --name pulsar-standalone \
  apachepulsar/pulsar:2.11.0 \
  bin/pulsar standalone
