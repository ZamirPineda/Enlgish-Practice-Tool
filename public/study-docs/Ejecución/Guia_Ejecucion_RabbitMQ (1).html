Guia_Ejecucion_RabbitMQ

Explicación

Esta guía te permitirá configurar y ejecutar una instancia básica de RabbitMQ localmente utilizando Podman o Docker. La configuración incluye la interfaz de gestión para facilitar la visualización y administración de las colas y mensajes. Para esta configuración, construiremos una imagen simple basada en la oficial y luego la ejecutaremos.

Pasos:

1. Crea el Dockerfile: Guarda el contenido proporcionado en un archivo llamado Dockerfile en un directorio vacío.

2. Construye la imagen: Ejecuta el comando docker build (o podman build) para crear tu imagen de RabbitMQ personalizada.

3. Ejecuta el contenedor: Utiliza el comando docker run (o podman run) para levantar el contenedor de RabbitMQ. Este comando:

  • * Ejecuta el contenedor en segundo plano (-d).
  • * Asigna el nombre some-rabbit al contenedor y my-rabbit como hostname.
  • * Mapea el puerto 15672 del host al puerto 15672 del contenedor para la interfaz de gestión web.
  • * Mapea el puerto 5672 del host al puerto 5672 del contenedor para el protocolo AMQP (Advanced Message Queuing Protocol).
  • * Establece las credenciales por defecto para la interfaz de gestión (RABBITMQ_DEFAULT_USER=user y RABBITMQ_DEFAULT_PASS=password).
  • * Monta un volumen persistente (rabbitmq_data) para asegurar que los datos de RabbitMQ (colas, intercambios, mensajes) no se pierdan al reiniciar el contenedor.

4. Accede a la interfaz de gestión: Una vez que el contenedor esté en funcionamiento, podrás acceder a la interfaz de gestión de RabbitMQ en tu navegador en http://localhost:15672 usando las credenciales user / password.

Comandos de Ejecución

docker build -t my-rabbitmq . && docker run -d --hostname my-rabbit --name some-rabbit -p 15672:15672 -p 5672:5672 -e RABBITMQ_DEFAULT_USER=user -e RABBITMQ_DEFAULT_PASS=password -v rabbitmq_data:/var/lib/rabbitmq my-rabbitmq

Archivos de Configuración

Dockerfile

# Usa la imagen oficial de RabbitMQ con el plugin de gestión ya incluido. Esta es la base para nuestra configuración básica.
FROM rabbitmq:3-management

# Exponer los puertos necesarios para RabbitMQ:
# 5672: Puerto estándar para el protocolo AMQP (Advanced Message Queuing Protocol), usado por los clientes para conectarse.
# 15672: Puerto para la interfaz de gestión web de RabbitMQ, donde puedes monitorear y administrar RabbitMQ.
EXPOSE 5672
EXPOSE 15672

# En este Dockerfile básico, no se realizan cambios adicionales a la imagen oficial.
# La imagen `rabbitmq:3-management` ya viene con lo necesario para una instancia básica con UI de gestión.
# Para configuraciones más avanzadas (ej. añadir plugins específicos, cambiar configuraciones de Erlang),
# se añadirían aquí directivas como `RUN rabbitmq-plugins enable --offline <plugin_name>`
# o `COPY rabbitmq.conf /etc/rabbitmq/rabbitmq.conf` para copiar archivos de configuración personalizados.
