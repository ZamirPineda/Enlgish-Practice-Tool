Guia_Ejecucion_NATS

Explicación

Esta guía le permitirá desplegar una instancia básica del servidor NATS utilizando Podman o Docker. NATS es un sistema de mensajería de alto rendimiento, ligero y escalable, diseñado para la comunicación de microservicios, IoT y la nube. Esta configuración incluye un Dockerfile que construye una imagen personalizada basada en la imagen oficial de NATS, e incorpora un archivo de configuración nats.conf para especificar los puertos de cliente y monitoreo. Los comandos podman build y podman run (o docker build y docker run) se utilizan para construir la imagen y levantar el contenedor, respectivamente. Una vez en ejecución, NATS estará disponible para clientes en el puerto 4222 y su interfaz de monitoreo HTTP en el puerto 8222.

Comandos de Ejecución

podman build -t my-nats-server . && podman run -d --name nats-server -p 4222:4222 -p 8222:8222 my-nats-server

Archivos de Configuración

Dockerfile

# Usa la imagen oficial de NATS como base.
# La imagen 'nats:latest' es adecuada para la mayoría de los casos.
FROM nats:latest

# Copia el archivo de configuración personalizado al contenedor.
# Se recomienda colocarlo en un directorio estándar como /etc/nats/.
COPY nats.conf /etc/nats/nats.conf

# Expone los puertos que NATS usará.
# 4222 es el puerto estándar para clientes NATS.
# 8222 es el puerto para la interfaz HTTP de monitoreo y estadísticas.
EXPOSE 4222
EXPOSE 8222

# Define el comando para iniciar el servidor NATS con el archivo de configuración.
# 'nats-server -c /etc/nats/nats.conf' le indica a NATS que use nuestra configuración personalizada.
CMD ["nats-server", "-c", "/etc/nats/nats.conf"]

nats.conf

# Puerto para clientes NATS.
# Este es el puerto principal al que los clientes se conectarán.
port: 4222

# Puerto para el servidor HTTP de monitoreo y información.
# Accede a http://localhost:8222/varz para ver estadísticas del servidor.
http_port: 8222

# Opcional: Configuración de logging (descomentar y ajustar si es necesario)
