Guia_Ejecucion_Weaviate

Explicación

Esta guía le permitirá configurar y ejecutar una instancia básica de Weaviate, un motor de búsqueda vectorial de código abierto, junto con un módulo de incrustación de Hugging Face (text2vec-huggingface) para generar vectores de texto localmente. Utilizaremos docker-compose para simplificar la configuración de ambos servicios y su comunicación.

Pasos para levantar la instancia:

1. Guarda los archivos: Crea una carpeta en tu sistema (ej. weaviate-local) y guarda el contenido del archivo docker-compose.yml proporcionado dentro de ella.

2. Ejecuta los contenedores: Abre una terminal en la carpeta donde guardaste docker-compose.yml y ejecuta el comando proporcionado en runCommands.

3. Verifica el estado: Una vez que los contenedores estén en ejecución, puedes verificar su estado con docker-compose ps.

4. Accede a Weaviate: Weaviate estará accesible en http://localhost:8080. Puedes usar herramientas como curl o un cliente Weaviate (Python, JavaScript, etc.) para interactuar con él. Por ejemplo, puedes verificar su estado de salud en http://localhost:8080/v1/meta.

Esta configuración utilizará el módulo text2vec-huggingface para generar incrustaciones (embeddings) de los datos que almacenes en Weaviate, lo que es fundamental para las capacidades de búsqueda semántica. El módulo de Hugging Face está configurado para ejecutarse en la CPU por defecto (ENABLE_CUDA: '0') para una mayor compatibilidad local, pero si tienes una GPU compatible con CUDA, puedes cambiar este valor a '1' para un mejor rendimiento.

Comandos de Ejecución

docker-compose up -d

Archivos de Configuración

docker-compose.yml

version: '3.8'
services:
  weaviate:
    image: semitechnologies/weaviate:1.24.1 # Usa una versión estable específica
    ports:
      - "8080:8080" # API RESTful
      - "50051:50051" # API gRPC
    restart: on-failure:0
    environment:
      QUERY_DEFAULTS_LIMIT: 20
      AUTHENTICATION_ANONYMOUS_ACCESS_ENABLED: 'true'
      PERSISTENCE_DATA_PATH: '/var/lib/weaviate'
      # Configura Weaviate para usar el módulo de incrustación de Hugging Face
      DEFAULT_VECTORIZER_MODULE: 'text2vec-huggingface'
      ENABLE_MODULES: 'text2vec-huggingface'
      # Apunta Weaviate al servicio del módulo de incrustación (nombre del servicio y puerto interno)
      TEXT2VEC_HUGGINGFACE_URL: 'http://huggingface-embedder:8080'
      CLUSTER_HOSTNAME: 'node1'
    volumes:
      - weaviate_data:/var/lib/weaviate # Persiste los datos de Weaviate

  huggingface-embedder:
    image: semitechnologies/huggingface-inference-api:sentence-transformers-multi-qa-distilbert-cos-v1 # Módulo de incrustación
    environment:
      # Opcional: establece '0' para deshabilitar CUDA si no está disponible o se desea ejecutar en CPU
      ENABLE_CUDA: '0'
      # Opcional: especifica un modelo específico para cargar, por ejemplo:
      # MODEL_NAME: 'sentence-transformers/all-MiniLM-L6-v2'
    # No se exponen puertos externamente ya que Weaviate lo accede internamente

volumes:
  weaviate_data:
