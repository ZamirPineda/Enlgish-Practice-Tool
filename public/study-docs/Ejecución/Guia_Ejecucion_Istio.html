Guía de Instalación de Istio Local con Minikube (Docker/Podman)

Esta guía te permitirá configurar una instancia básica de Istio en tu máquina local utilizando Minikube, que a su vez usa Docker o Podman como driver. Istio es un "Service Mesh" que se ejecuta sobre Kubernetes, por lo que primero necesitamos un clúster de Kubernetes local.

Prerrequisitos:

  • kubectl: Herramienta de línea de comandos para interactuar con clústeres de Kubernetes.
  • Minikube: Herramienta para ejecutar un clúster de Kubernetes de un solo nodo localmente.
  • istioctl: Herramienta de línea de comandos de Istio. Descárgala de la página oficial de Istio y añádela a tu PATH.
  • Docker o Podman: Un runtime de contenedor instalado y configurado (Minikube lo usará como driver).

Pasos para la Configuración:

1. Asegúrate de tener los prerrequisitos instalados y configurados. Si no los tienes, puedes encontrarlos en sus sitios web oficiales.

2. Crea los siguientes archivos en un directorio de trabajo vacío (o en el directorio que prefieras):

  • * bookinfo.yaml
  • * bookinfo-gateway.yaml
  • * Dockerfile (ejemplo de una aplicación Nginx, no directamente usada por la aplicación Bookinfo)
  • * index.html (para el Dockerfile de ejemplo de Nginx)

3. Ejecuta el comando runCommands proporcionado. Este comando iniciará Minikube, instalará Istio con el perfil demo, habilitará la inyección automática de sidecars de Istio en el namespace default, y finalmente desplegará la aplicación de ejemplo Bookinfo junto con su Gateway de entrada.

    minikube start --driver=docker && \
    echo "Minikube iniciado. Instalando Istio..." && \
    istioctl install --set profile=demo -y && \
    echo "Istio instalado. Habilitando la inyección de sidecars para el namespace 'default'..." && \
    kubectl label namespace default istio-injection=enabled --overwrite=true && \
    echo "Desplegando la aplicación Bookinfo..." && \
    kubectl apply -f bookinfo.yaml && \
    echo "Desplegando el Istio Gateway para Bookinfo..." && \
    kubectl apply -f bookinfo-gateway.yaml

4. Verifica los componentes de Istio y Bookinfo. Puedes necesitar esperar unos minutos para que todos los pods se inicien y estén en estado Running.

    kubectl get pods -n istio-system
    kubectl get pods

5. Habilita el túnel de Minikube en una terminal separada. Esto es crucial para acceder al Ingress Gateway de Istio desde tu máquina local:

    minikube tunnel

Mantén esta terminal abierta y el comando ejecutándose. Podría pedirte tu contraseña de administrador para configurar las rutas de red.

6. Accede a la aplicación Bookinfo. Una vez que minikube tunnel esté ejecutándose, el Ingress Gateway de Istio será accesible en 127.0.0.1 (puerto 80 por defecto). Puedes verificarlo con:

    curl http://127.0.0.1/productpage

Si todo está configurado correctamente, verás la salida HTML de la página de producto de Bookinfo. También puedes abrir http://127.0.0.1/productpage en tu navegador web.

7. Explora los dashboards de Istio (opcional):

Una vez que la aplicación esté funcionando, puedes acceder a los dashboards de Istio para visualizar la malla de servicios:

  • * istioctl dashboard kiali (para ver la topología del servicio)
  • * istioctl dashboard prometheus (para métricas)
  • * istioctl dashboard grafana (para paneles de control)

Nota sobre Dockerfiles:

El archivo Dockerfile y index.html proporcionados son un ejemplo de cómo podrías crear tu propia aplicación Nginx para desplegar en Istio. La configuración principal de esta guía utiliza la aplicación de ejemplo Bookinfo de Istio, que ya usa imágenes de contenedor pre-construidas y no requiere Dockerfiles personalizados para su despliegue.

Comandos de Ejecución

minikube start --driver=docker && echo "Minikube iniciado. Instalando Istio..." && istioctl install --set profile=demo -y && echo "Istio instalado. Habilitando la inyección de sidecars para el namespace 'default'..." && kubectl label namespace default istio-injection=enabled --overwrite=true && echo "Desplegando la aplicación Bookinfo..." && kubectl apply -f bookinfo.yaml && echo "Desplegando el Istio Gateway para Bookinfo..." && kubectl apply -f bookinfo-gateway.yaml

Dockerfile

FROM nginx:latest
LABEL author="AI Assistant"
COPY index.html /usr/share/nginx/html/index.html
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]

bookinfo-gateway.yaml

apiVersion: networking.istio.io/v1alpha3
kind: Gateway
metadata:
  name: bookinfo-gateway
spec:
  selector:
    istio: ingressgateway # use Istio default gateway
  servers:
  - port:
      number: 80
      name: http
      protocol: HTTP
    hosts:
    - "*"
---
apiVersion: networking.istio.io/v1alpha3
kind: VirtualService
metadata:
  name: bookinfo
spec:
  hosts:
  - "*"
  gateways:
  - bookinfo-gateway
  http:
  - match:
    - uri:
        exact: /productpage
    - uri:
        prefix: /static
    - uri:
        exact: /login
    - uri:
        exact: /logout
    - uri:
        prefix: /api/v1/products
    route:
    - destination:
        host: productpage
        port:
          number: 9080
