Guia_Ejecucion_Terraform

Explicación

Esta guía te permitirá configurar y ejecutar Terraform localmente utilizando Podman (o Docker) para gestionar tu infraestructura como código. Crearemos una imagen de contenedor personalizada que incluirá la CLI de Terraform. Luego, ejecutaremos comandos de Terraform dentro de este contenedor, montando tu directorio de trabajo local para que puedas interactuar con tus archivos .tf.

Pasos a seguir:

1. Guarda el contenido del Dockerfile y main.tf en el mismo directorio local.

2. Asegúrate de tener Podman (o Docker) instalado y funcionando.

3. Asegúrate de tener tus credenciales de AWS configuradas en tu entorno local (ej. exportando AWS_ACCESS_KEY_ID y AWS_SECRET_ACCESS_KEY o configurando el archivo ~/.aws/credentials).

4. Ejecuta el comando podman build para construir la imagen de Terraform.

5. Ejecuta los comandos podman run para inicializar, planificar y aplicar tu configuración de Terraform.

Comandos de Ejecución

podman build -t my-terraform-cli .
podman run --rm -it -v "$(pwd):/app" -e "AWS_ACCESS_KEY_ID=${AWS_ACCESS_KEY_ID}" -e "AWS_SECRET_ACCESS_KEY=${AWS_SECRET_ACCESS_KEY}" -w /app my-terraform-cli init
podman run --rm -it -v "$(pwd):/app" -e "AWS_ACCESS_KEY_ID=${AWS_ACCESS_KEY_ID}" -e "AWS_SECRET_ACCESS_KEY=${AWS_SECRET_ACCESS_KEY}" -w /app my-terraform-cli plan
# Para aplicar los cambios (¡procede con precaución en entornos reales!)
# podman run --rm -it -v "$(pwd):/app" -e "AWS_ACCESS_KEY_ID=${AWS_ACCESS_KEY_ID}" -e "AWS_SECRET_ACCESS_KEY=${AWS_SECRET_ACCESS_KEY}" -w /app my-terraform-cli apply
# Para destruir los recursos creados
# podman run --rm -it -v "$(pwd):/app" -e "AWS_ACCESS_KEY_ID=${AWS_ACCESS_KEY_ID}" -e "AWS_SECRET_ACCESS_KEY=${AWS_SECRET_ACCESS_KEY}" -w /app my-terraform-cli destroy

Archivos de Configuración

Dockerfile

# Usa una imagen base ligera de Alpine Linux
FROM alpine:latest

# Define la versión de Terraform a instalar
ARG TERRAFORM_VERSION="1.8.0"

# Instala dependencias para descargar y descomprimir Terraform
RUN apk add --no-cache curl unzip bash

# Descarga e instala Terraform desde las releases oficiales de HashiCorp
RUN curl -LO "https://releases.hashicorp.com/terraform/${TERRAFORM_VERSION}/terraform_${TERRAFORM_VERSION}_linux_amd64.zip" && \
    unzip "terraform_${TERRAFORM_VERSION}_linux_amd64.zip" -d /usr/local/bin/ && \
    rm "terraform_${TERRAFORM_VERSION}_linux_amd64.zip"

# Verifica la instalación y muestra la versión de Terraform
RUN terraform version

# Establece el punto de entrada por defecto para el contenedor. 
# Esto significa que cuando ejecutes `podman run my-terraform-cli <comando>`, 
# el contenedor ejecutará `terraform <comando>`.
ENTRYPOINT ["terraform"]

# Define un comando por defecto si no se proporciona ninguno
CMD ["--help"]

main.tf

# Define el proveedor de AWS
# Asegúrate de haber configurado tus credenciales de AWS en tu entorno local
# (ej. variables de entorno AWS_ACCESS_KEY_ID y AWS_SECRET_ACCESS_KEY)
provider "aws" {
  region = "us-east-1" # Puedes cambiar la región según tu preferencia
}

# Crea un bucket S3 de ejemplo
resource "aws_s3_bucket" "example_bucket" {
  # ¡Importante!: El nombre del bucket S3 debe ser globalmente único en AWS.
  # Cámbialo por uno que sea único para ti (ej. combinando tu nombre y un sufijo aleatorio).
  bucket = "my-unique-terraform-bucket-yourname-1234"
  acl    = "private"

  tags = {
    Environment = "Dev"
    Project     = "TerraformGuide"
    ManagedBy   = "Terraform"
  }
}

# Define una salida para mostrar el nombre del bucket S3 una vez creado
output "bucket_name" {
  value       = aws_s3_bucket.example_bucket.id
  description = "El nombre del bucket S3 creado por Terraform."
}
