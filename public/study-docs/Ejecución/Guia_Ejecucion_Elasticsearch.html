Guia_Ejecucion_Elasticsearch

Explicación

Esta guía proporciona una configuración básica para ejecutar Elasticsearch y Kibana localmente utilizando Docker Compose (compatible con Podman Compose).

Archivos incluidos:

  • docker-compose.yml: Define dos servicios:
  • * Elasticsearch: La base de datos de búsqueda y analítica. Está configurado como un clúster de un solo nodo para desarrollo local. Se le asigna 1GB de memoria JVM y se deshabilita la seguridad X-Pack para facilitar el acceso. Se mapean los puertos 9200 (HTTP) y 9300 (transporte).
  • * Kibana: La interfaz de usuario para visualizar y gestionar los datos de Elasticsearch. Se mapea al puerto 5601.

Pasos a seguir:

1. Requisito previo para Elasticsearch: Elasticsearch requiere una configuración específica del sistema operativo anfitrión. Asegúrate de que vm.max_map_count sea al menos 262144. Puedes verificarlo con sysctl vm.max_map_count y establecerlo con sudo sysctl -w vm.max_map_count=262144.

2. Guarda el contenido de docker-compose.yml en un archivo con ese nombre en tu directorio de trabajo.

3. Abre una terminal en el mismo directorio.

4. Ejecuta el comando docker-compose up -d (o podman-compose up -d si usas Podman Compose) para iniciar los contenedores.

5. Espera unos minutos a que los servicios se inicien completamente.

6. Una vez levantados, puedes acceder a:

  • * Elasticsearch: http://localhost:9200 (Verifica su estado con http://localhost:9200/_cat/health?v)
  • * Kibana: http://localhost:5601

Para detener los servicios:

En el mismo directorio, ejecuta docker-compose down (o podman-compose down). Esto detendrá y eliminará los contenedores, pero conservará los volúmenes de datos a menos que uses docker-compose down -v.

Comandos de Ejecución

docker-compose up -d

Archivos de Configuración

docker-compose.yml

version: '3.8'

services:
  elasticsearch:
    image: docker.elastic.co/elasticsearch/elasticsearch:7.17.6
    container_name: elasticsearch
    environment:
      - discovery.type=single-node
      - ES_JAVA_OPTS=-Xms1g -Xmx1g
      - xpack.security.enabled=false
      - cluster.name=docker-cluster
      - bootstrap.memory_lock=true
    ulimits:
      memlock:
        soft: -1
        hard: -1
    volumes:
      - esdata:/usr/share/elasticsearch/data
    ports:
      - "9200:9200"
      - "9300:9300"
    healthcheck:
      test: ["CMD-SHELL", "curl -s -f http://localhost:9200/_cat/health > /dev/null || exit 1"]
      interval: 10s
      timeout: 10s
      retries: 10

  kibana:
    image: docker.elastic.co/kibana/kibana:7.17.6
    container_name: kibana
    ports:
      - "5601:5601"
    environment:
      - ELASTICSEARCH_HOSTS=http://elasticsearch:9200
    depends_on:
      elasticsearch:
        condition: service_healthy
    healthcheck:
      test: ["CMD-SHELL", "curl -s -f http://localhost:5601/api/status > /dev/null || exit 1"]
      interval: 10s
      timeout: 10s
      retries: 10

volumes:
  esdata:
    driver: local
