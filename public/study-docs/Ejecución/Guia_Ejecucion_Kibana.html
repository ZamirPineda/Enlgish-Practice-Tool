Guia_Ejecucion_Kibana

Explicación

Esta guía le permitirá configurar una instancia básica de Kibana junto con Elasticsearch utilizando Docker Compose (o Podman Compose, si lo tiene configurado). Los archivos proporcionados configuran dos servicios: Elasticsearch, que almacenará los datos, y Kibana, que proporcionará la interfaz de usuario para visualizar y explorar esos datos. La configuración es para un nodo único y está optimizada para el desarrollo local con un uso de memoria limitado para Elasticsearch. Una vez iniciados, podrá acceder a Kibana a través de su navegador web.

Comandos de Ejecución

docker-compose up -d

Archivos de Configuración

docker-compose.yml

version: '3.8'
services:
  elasticsearch:
    image: docker.elastic.co/elasticsearch/elasticsearch:7.17.6
    container_name: elasticsearch
    environment:
      - discovery.type=single-node
      - ES_JAVA_OPTS=-Xms512m -Xmx512m
      - xpack.security.enabled=false
    ports:
      - "9200:9200"
      - "9300:9300"
    volumes:
      - esdata:/usr/share/elasticsearch/data
    healthcheck:
      test: ["CMD-SHELL", "curl -s http://localhost:9200/_cluster/health | grep -q '"status":"green"' || curl -s http://localhost:9200/_cluster/health | grep -q '"status":"yellow"'"]
      interval: 10s
      timeout: 10s
      retries: 5

  kibana:
    image: docker.elastic.co/kibana/kibana:7.17.6
    container_name: kibana
    environment:
      - ELASTICSEARCH_HOSTS=http://elasticsearch:9200
      - KIBANA_SYSTEM_PASSWORD=password
    ports:
      - "5601:5601"
    depends_on:
      elasticsearch:
        condition: service_healthy

volumes:
  esdata:
