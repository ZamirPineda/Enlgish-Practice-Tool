Guia_Ejecucion_Redis Pub/Sub

Explicación

Esta guía te permitirá levantar una instancia básica de Redis para usar su funcionalidad Pub/Sub. Redis Pub/Sub (Publicador/Suscriptor) es un sistema de mensajería donde los remitentes (publicadores) no envían mensajes directamente a los receptores (suscriptores). En su lugar, publican mensajes en canales, y los suscriptores se registran en los canales que les interesan. Redis gestiona la distribución de estos mensajes. Este enfoque permite una comunicación desacoplada entre diferentes componentes de una aplicación.

Configuración y Pasos a Seguir

1. Levantar el Contenedor Redis: Ejecuta el siguiente comando en tu terminal para iniciar una instancia de Redis. Esto descargará la imagen oficial de Redis si no la tienes, creará y ejecutará un contenedor llamado my-redis-pubsub, y mapeará el puerto 6379 del contenedor al puerto 6379 de tu máquina local. 

    docker run --name my-redis-pubsub -p 6379:6379 -d redis:latest

O si prefieres Podman: 

    podman run --name my-redis-pubsub -p 6379:6379 -d redis:latest

2. Conectarse a Redis y Suscribirse:

Abre una nueva terminal y conéctate a la instancia de Redis usando redis-cli. Luego, suscríbete a un canal, por ejemplo, mi_canal. 

    docker exec -it my-redis-pubsub redis-cli  
    SUBSCRIBE mi_canal

Verás que el cliente se queda esperando mensajes en esta terminal.

3. Publicar Mensajes:

Abre otra nueva terminal, conéctate de nuevo a redis-cli y publica uno o varios mensajes en mi_canal. 

    docker exec -it my-redis-pubsub redis-cli  
    PUBLISH mi_canal "Hola, mundo!"  
    PUBLISH mi_canal "Este es otro mensaje desde el publicador."

4. Verificar la Suscripción:

Vuelve a la terminal donde te suscribiste (SUBSCRIBE mi_canal). Deberías ver los mensajes que publicaste aparecer allí de forma asíncrona. 

    1) "message"  
    2) "mi_canal"  
    3) "Hola, mundo!"  
    1) "message"  
    2) "mi_canal"  
    3) "Este es otro mensaje desde el publicador."

5. Limpiar (Opcional): Cuando hayas terminado con la prueba, puedes detener y eliminar el contenedor Redis con los siguientes comandos: 

    docker stop my-redis-pubsub  
    docker rm my-redis-pubsub

Comandos de Ejecución
