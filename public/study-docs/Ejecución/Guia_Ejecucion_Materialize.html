Guia_Ejecucion_Materialize

Explicación

Esta guía te permitirá levantar una instancia básica de Materialize localmente. Materialize es una base de datos de streaming que te permite crear vistas materializadas en tiempo real a partir de diversas fuentes de datos (Kafka, PostgreSQL, etc.).

Pasos para ejecutar:

1. Guarda los archivos: Crea un directorio, por ejemplo, materialize-setup, y guarda el Dockerfile proporcionado dentro de él.

2. Construye la imagen: Abre una terminal en el directorio materialize-setup y ejecuta el siguiente comando para construir la imagen de Podman/Docker. Este paso es necesario ya que estamos proporcionando un Dockerfile para demostrar la estructura, aunque Materialize también se puede ejecutar directamente desde su imagen oficial.

    podman build -t my-materialize .
    # o si usas Docker:
    # docker build -t my-materialize .

3. Inicia el contenedor: Una vez construida la imagen, puedes iniciar el contenedor de Materialize con el comando runCommands que se proporciona a continuación.

4. Conéctate a Materialize: Materialize expone una interfaz de cliente compatible con PostgreSQL en el puerto 6875. Puedes conectarte usando cualquier cliente PostgreSQL (como psql):

    psql -h localhost -p 6875 -U materialize

(La contraseña no es necesaria por defecto para el usuario materialize en una instalación básica).

Este setup te dará una instancia de Materialize lista para recibir datos y ejecutar consultas SQL en tiempo real.

Comandos de Ejecución

podman run --rm -p 6875:6875 --name materialize-instance my-materialize

Archivos de Configuración

Dockerfile

# Utiliza la imagen oficial de Materialize como base.
# Esto garantiza que tenemos la última versión estable de Materialize.
FROM materialize/materialize:v0.25.1

# El puerto 6875 es el puerto SQL por defecto de Materialize.
# Aunque Materialize ya lo expone internamente, es una buena práctica documentarlo.
EXPOSE 6875

# Materialize inicia automáticamente su servicio cuando el contenedor arranca.
# No necesitamos un comando CMD o ENTRYPOINT explícito aquí, ya que la imagen base ya lo proporciona.
# Por defecto, Materialize se ejecuta en modo standalone, escuchando conexiones SQL.
