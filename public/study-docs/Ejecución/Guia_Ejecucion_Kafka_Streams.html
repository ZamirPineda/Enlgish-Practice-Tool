Guia_Ejecucion_Kafka Streams

Explicación

Esta guía proporciona una configuración básica para ejecutar una aplicación Kafka Streams junto con un clúster de Apache Kafka (Zookeeper + Broker) usando Docker Compose. La aplicación de ejemplo de Kafka Streams leerá mensajes de un tema de entrada ('streams-plaintext-input'), convertirá el texto a mayúsculas y escribirá el resultado en un tema de salida ('streams-uppercase-output').

Pasos a seguir:

1. Crear los archivos: Guarda los contenidos proporcionados en sus respectivos archivos y directorios. Asegúrate de crear el directorio src/main/java/com/example/ para el archivo StreamApp.java.

2. Dar permisos al script: chmod +x create-topics.sh

3. Iniciar el clúster y la aplicación: Ejecuta docker-compose up -d. Esto levantará Zookeeper, Kafka y construirá/ejecutará la aplicación Kafka Streams.

4. Crear temas de Kafka: Una vez que Kafka esté en funcionamiento (puede tardar unos segundos), ejecuta ./create-topics.sh para crear los temas necesarios.

5. Probar la aplicación:

  • * Envía un mensaje al tema de entrada: docker exec -it kafka-broker kafka-console-producer.sh --broker-list localhost:9092 --topic streams-plaintext-input (luego escribe tus mensajes, ej: "hello world", "Kafka Streams").
  • * Consume mensajes del tema de salida para ver el resultado: docker exec -it kafka-broker kafka-console-consumer.sh --bootstrap-server localhost:9092 --topic streams-uppercase-output --from-beginning

6. Ver logs de la aplicación Streams: docker logs kafka-streams-app

7. Detener la configuración: docker-compose down

Dockerfile.streams-app

# Usa una imagen base de OpenJDK para compilar y ejecutar la aplicación Java
FROM openjdk:11-jdk-slim as builder

# Establece el directorio de trabajo dentro del contenedor
WORKDIR /app

# Instala Maven
RUN apt-get update && apt-get install -y maven

# Copia los archivos de configuración de Maven y el código fuente
COPY pom.xml .
COPY src ./src

# Compila la aplicación usando Maven
# --batch-mode para ejecución no interactiva
# -DskipTests para saltar las pruebas durante la compilación
# package para empaquetar la aplicación en un JAR ejecutable
RUN mvn clean package -DskipTests

# Fase de ejecución
FROM openjdk:11-jre-slim

# Establece el directorio de trabajo
WORKDIR /app

# Copia el JAR compilado de la fase de construcción
COPY --from=builder /app/target/kafka-streams-example-1.0-SNAPSHOT.jar kafka-streams-example.jar

# Define el punto de entrada para ejecutar la aplicación
# java -jar <nombre_del_jar>
ENTRYPOINT ["java", "-jar", "kafka-streams-example.jar"]

docker-compose.yml

version: '3.8'

services:
  zookeeper:
    image: confluentinc/cp-zookeeper:7.4.0
    hostname: zookeeper
    ports:
      - "2181:2181"
    environment:
      ZOOKEEPER_CLIENT_PORT: 2181
      ZOOKEEPER_TICK_TIME: 2000

  kafka-broker:
    image: confluentinc/cp-kafka:7.4.0
    hostname: kafka-broker
    container_name: kafka-broker
    depends_on:
      - zookeeper
    ports:
      - "9092:9092"
    environment:
      KAFKA_BROKER_ID: 1
      KAFKA_ZOOKEEPER_CONNECT: zookeeper:2181
      KAFKA_ADVERTISED_LISTENERS: PLAINTEXT://kafka-broker:29092,PLAINTEXT_HOST://localhost:9092
      KAFKA_LISTENER_SECURITY_PROTOCOL_MAP: PLAINTEXT:PLAINTEXT,PLAINTEXT_HOST:PLAINTEXT
      KAFKA_INTER_BROKER_LISTENER_NAME: PLAINTEXT
      KAFKA_OFFSETS_TOPIC_REPLICATION_FACTOR: 1
      KAFKA_TRANSACTION_STATE_LOG_MIN_ISR: 1
      KAFKA_TRANSACTION_STATE_LOG_REPLICATION_FACTOR: 1

  kafka-streams-app:
    build:
      context: .
      dockerfile: Dockerfile.streams-app
    depends_on:
      - kafka-broker
    environment:
      # Asegúrate de que la aplicación Kafka Streams se conecte al broker
      # El broker es accesible por su nombre de servicio 'kafka-broker' dentro de la red Docker Compose.
      KAFKA_BOOTSTRAP_SERVERS: kafka-broker:29092
    # Puedes añadir más variables de entorno si tu aplicación las necesita
    # ports:
    #   - "8080:8080" # Mapea un puerto si quieres acceder a alguna interfaz web de tu app (no aplica para este ejemplo)

create-topics.sh

#!/bin/bash
echo "Waiting for Kafka to be ready..."

# Wait until Kafka broker is up and running
# The following loop attempts to connect to Kafka's internal port
# for topic creation. 'kafka-broker' is the service name in docker-compose.
while ! nc -z kafka-broker 29092; do
  sleep 1
done

echo "Kafka broker is up. Creating topics..."

# Create input topic
docker exec kafka-broker kafka-topics.sh --create --topic streams-plaintext-input --bootstrap-server localhost:9092 --partitions 1 --replication-factor 1 --if-not-exists

# Create output topic
docker exec kafka-broker kafka-topics.sh --create --topic streams-uppercase-output --bootstrap-server localhost:9092 --partitions 1 --replication-factor 1 --if-not-exists

echo "Topics created successfully: streams-plaintext-input, streams-uppercase-output"

src/main/java/com/example/StreamApp.java

package com.example;

import org.apache.kafka.common.serialization.Serdes;
import org.apache.kafka.streams.KafkaStreams;
import org.apache.kafka.streams.StreamsBuilder;
import org.apache.kafka.streams.StreamsConfig;
import org.apache.kafka.streams.Topology;
import org.apache.kafka.streams.kstream.Consumed;
import org.apache.kafka.streams.kstream.Produced;

import java.util.Properties;

public class StreamApp {

    public static void main(String[] args) {
        // Configuración de la aplicación Kafka Streams
        Properties props = new Properties();
        props.put(StreamsConfig.APPLICATION_ID_CONFIG, "streams-uppercase-app");
        // KAFKA_BOOTSTRAP_SERVERS se inyecta como variable de entorno desde docker-compose.yml
        props.put(StreamsConfig.BOOTSTRAP_SERVERS_CONFIG, System.getenv("KAFKA_BOOTSTRAP_SERVERS"));
        props.put(StreamsConfig.DEFAULT_KEY_SERDE_CLASS_CONFIG, Serdes.String().getClass());
        props.put(StreamsConfig.DEFAULT_VALUE_SERDE_CLASS_CONFIG, Serdes.String().getClass());

        // Construye la topología de la aplicación Kafka Streams
        StreamsBuilder builder = new StreamsBuilder();
        builder.stream("streams-plaintext-input", Consumed.with(Serdes.String(), Serdes.String()))
                .mapValues(value -> value.toUpperCase()) // Convierte el valor a mayúsculas
                .to("streams-uppercase-output", Produced.with(Serdes.String(), Serdes.String()));

        Topology topology = builder.build();
        System.out.println(topology.describe()); // Imprime la descripción de la topología en los logs

        // Crea y arranca la aplicación Kafka Streams
        KafkaStreams streams = new KafkaStreams(topology, props);
        // Limpiar el estado local de la aplicación (útil para desarrollo, no para producción)
        // streams.cleanUp(); // Descomentar para limpiar el estado local al iniciar (útil en desarrollo)
        streams.start();

        // Añade un hook de apagado para cerrar la aplicación de Streams de forma elegante
        Runtime.getRuntime().addShutdownHook(new Thread(streams::close));
    }
}
