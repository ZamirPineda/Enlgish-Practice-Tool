Configuración de TimescaleDB con Podman/Docker

Esta guía te permitirá levantar una instancia básica de TimescaleDB utilizando la imagen oficial de Docker. TimescaleDB es una base de datos de series temporales construida como una extensión sobre PostgreSQL. La configuración incluye:

  • Uso de la imagen oficial: Se utilizará la imagen timescale/timescaledb:latest-pg15 que ya incluye PostgreSQL y la extensión TimescaleDB preinstalados y configurados.
  • Persistencia de datos: Se creará un volumen de Podman/Docker llamado timescaledb_data para asegurar que los datos de la base de datos persistan incluso si el contenedor se detiene o se elimina.
  • Mapeo de puertos: El puerto 5432 del contenedor (puerto por defecto de PostgreSQL) se mapeará al puerto 5432 de tu máquina local, permitiendo la conexión desde herramientas cliente.
  • Contraseña de PostgreSQL: Se establecerá una contraseña para el usuario postgres a través de la variable de entorno POSTGRES_PASSWORD.

Pasos a seguir:

1. Asegúrate de tener Podman o Docker instalado y funcionando en tu sistema.

2. Ejecuta el comando proporcionado en la sección runCommands.

3. Una vez que el contenedor esté en ejecución, podrás conectarte a la base de datos utilizando cualquier cliente PostgreSQL (ej. psql) a localhost:5432 con el usuario postgres y la contraseña mysecretpassword.

4. Para verificar que TimescaleDB está funcionando, puedes conectarte y ejecutar CREATE EXTENSION IF NOT EXISTS timescaledb; (si aún no está habilitada) y luego SELECT * FROM timescaledb_information.licenses;.

No se requieren dockerfiles ni supportFiles adicionales, ya que la imagen oficial es suficiente para una configuración básica y las opciones se pasan directamente en el comando de ejecución.

Comandos de Ejecución

podman run --name timescaledb -e POSTGRES_PASSWORD=mysecretpassword -p 5432:5432 -v timescaledb_data:/var/lib/postgresql/data -d timescale/timescaledb:latest-pg15
