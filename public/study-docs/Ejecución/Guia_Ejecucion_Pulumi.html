Guia_Ejecucion_Pulumi

Explicación

Esta guía le permitirá ejecutar el CLI de Pulumi dentro de un contenedor Docker/Podman. Pulumi es una herramienta de Infraestructura como Código (IaC) que le permite definir y gestionar su infraestructura en la nube utilizando lenguajes de programación. Ejecutar Pulumi en un contenedor es útil para:

1. Aislamiento: Mantener las dependencias de Pulumi separadas de su sistema anfitrión.

2. Consistencia: Asegurar que todos los miembros del equipo usen la misma versión de Pulumi.

3. CI/CD: Facilita la integración en pipelines de integración y despliegue continuo.

La configuración incluye un Dockerfile que construye una imagen con el CLI de Pulumi y Node.js (necesario para proyectos Pulumi basados en TypeScript/JavaScript). También se proporcionan un archivo Pulumi.yaml y un index.ts con un proyecto Pulumi mínimo de ejemplo que genera un UUID aleatorio, que no requiere credenciales de nube. Este proyecto sirve para demostrar que Pulumi puede ejecutarse y gestionar un recurso.

Pasos para Ejecutar:

1. Crear un directorio de proyecto: Cree una carpeta vacía, por ejemplo, my-pulumi-project.

2. Guardar los archivos: Coloque el Dockerfile, Pulumi.yaml y index.ts proporcionados dentro de este directorio.

3. Instalar dependencias del proyecto (opcional pero recomendado): Dentro de su directorio my-pulumi-project, ejecute npm install @pulumi/pulumi @pulumi/random. Esto creará el directorio node_modules que será montado en el contenedor.

4. Obtener un Token de Acceso de Pulumi: Necesitará un token de acceso de Pulumi para autenticarse con el servicio de Pulumi (para gestionar estados). Puede generarlo en [app.pulumi.com](https://app.pulumi.com) en la sección de configuración de su cuenta.

5. Ejecutar los comandos: Utilice los runCommands proporcionados para construir la imagen y luego ejecutar el proyecto Pulumi. Asegúrese de reemplazar con su token real.

Una vez completado el pulumi up, puede ver el UUID generado ejecutando:

docker run --rm -it -v "$(pwd):/app" -w /app -e PULUMI_ACCESS_TOKEN="<your_pulumi_access_token>" pulumi-cli stack output outputUuid

Para eliminar los recursos creados (el UUID aleatorio en el servicio de Pulumi, no el UUID en sí), ejecute:

docker run --rm -it -v "$(pwd):/app" -w /app -e PULUMI_ACCESS_TOKEN="<your_pulumi_access_token>" pulumi-cli destroy --yes

Comandos de Ejecución

# Paso 1: Construir la imagen del CLI de Pulumi
docker build -t pulumi-cli .

# Paso 2: Ejecutar el comando 'pulumi up' para desplegar la infraestructura.
# Asegúrate de reemplazar '<your_pulumi_access_token>' con tu token de acceso de Pulumi real.
# Este token es necesario para autenticarse con el servicio de Pulumi.
# Puedes obtenerlo desde la consola de Pulumi en app.pulumi.com.
# El volumen '-v "$(pwd):/app"' mapea tu directorio de proyecto local al contenedor,
# y '-w /app' establece el directorio de trabajo dentro del contenedor.
docker run --rm -it \
  -v "$(pwd):/app" \
  -w /app \
  -e PULUMI_ACCESS_TOKEN="<your_pulumi_access_token>" \
  pulumi-cli up --yes

Archivos de Configuración

Dockerfile

# Dockerfile para Pulumi CLI con soporte para proyectos Node.js
FROM node:18-alpine

LABEL maintainer="Your Name <your.email@example.com>"

# Instalar dependencias necesarias para Pulumi CLI
RUN apk add --no-cache curl unzip

# Descargar e instalar Pulumi CLI
# Puedes especificar una versión de Pulumi si lo deseas, ej: ENV PULUMI_VERSION="3.90.0"
ENV PULUMI_VERSION="3.90.0"

RUN PULUMI_CLI_URL="https://github.com/pulumi/pulumi/releases/download/v${PULUMI_VERSION}/pulumi-v${PULUMI_VERSION}-linux-x64.tar.gz" && \
    curl -L ${PULUMI_CLI_URL} -o /tmp/pulumi.tar.gz && \
    tar -xzf /tmp/pulumi.tar.gz -C /usr/local/bin && \
    rm /tmp/pulumi.tar.gz && \
    chmod +x /usr/local/bin/pulumi/pulumi && \
    ln -s /usr/local/bin/pulumi/pulumi /usr/local/bin/pulumi

# Configurar el PATH para que el comando pulumi esté disponible
ENV PATH="/usr/local/bin/pulumi:${PATH}"

# Establecer el punto de entrada predeterminado al comando 'pulumi'
ENTRYPOINT ["pulumi"]

# Por defecto, puedes mostrar la versión o ayuda si no se proporcionan argumentos
CMD ["version"]

Pulumi.yaml

name: my-first-pulumi-project
runtime: nodejs
description: Un proyecto Pulumi mínimo para demostrar la ejecución local.

index.ts

import * as pulumi from "@pulumi/pulumi";
import * as random from "@pulumi/random";

// Crea un UUID aleatorio usando el proveedor 'random'
const myRandomUuid = new random.RandomUuid("myRandomUuid");

// Exporta el UUID generado como una salida de la pila
export const outputUuid = myRandomUuid.id;

// Para ver esta salida después de 'pulumi up', puedes ejecutar:
// pulumi stack output outputUuid
