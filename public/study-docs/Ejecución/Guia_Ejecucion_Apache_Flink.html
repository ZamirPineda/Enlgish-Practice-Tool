Guia_Ejecucion_Apache Flink

Explicación

Esta guía te permitirá desplegar una instancia básica de Apache Flink localmente utilizando Docker Compose. Flink es un framework y motor de procesamiento de flujos de datos distribuidos para cálculos con estado y a gran escala.

La configuración incluye los siguientes componentes:

  • JobManager: Es el coordinador central del clúster de Flink. Es responsable de recibir las aplicaciones Flink, programar los trabajos y gestionar los TaskManagers. También expone la interfaz de usuario web de Flink para monitorear los trabajos.
  • TaskManager: Son los trabajadores que ejecutan las tareas de procesamiento de datos, almacenan en búfer y intercambian datos. Un TaskManager ejecuta uno o más 'task slots', que son unidades de recursos.

Se utilizarán dos Dockerfiles mínimos que extienden las imágenes oficiales de Flink para demostrar cómo se podría personalizar la configuración, aunque para un setup básico no son estrictamente necesarios. El archivo docker-compose.yml orquestará el JobManager y un TaskManager, enlazándolos a través de una red definida y exponiendo la UI de Flink en el puerto 8081 de tu máquina local.

Comandos de Ejecución

docker-compose up -d

Archivos de Configuración

jobmanager/Dockerfile

# Dockerfile para el JobManager de Apache Flink
# Utiliza la imagen oficial de Flink como base para el JobManager.
# Este Dockerfile es mínimo; puedes añadir aquí dependencias adicionales,
# conectores de Flink, o configuraciones específicas si tu aplicación lo requiere.
FROM flink:1.17-scala_2.12

# Para un setup básico, la imagen oficial ya incluye todo lo necesario.

docker-compose.yml

version: "3.8"
services:
  jobmanager:
    build: ./jobmanager # Usa el Dockerfile en el subdirectorio jobmanager
    hostname: jobmanager # Nombre del host para que los TaskManagers puedan encontrarlo
    ports:
      - "8081:8081" # Puerto de la interfaz de usuario web de Flink
    environment:
      # Configura la dirección RPC del JobManager para que los TaskManagers se conecten
      - FLINK_PROPERTIES_JOBMANAGER_RPC_ADDRESS=jobmanager
      # Número de slots de tarea por TaskManager (uno por defecto)
      - FLINK_PROPERTIES_TASKMANAGER_NUMBER_OF_TASK_SLOTS=1
    volumes:
      # Monta un volumen para persistir los logs del JobManager
      - ./logs/jobmanager:/opt/flink/log
    networks:
      - flink-network

  taskmanager:
    build: ./taskmanager # Usa el Dockerfile en el subdirectorio taskmanager
    hostname: taskmanager
    environment:
      # Los TaskManagers deben saber cómo encontrar al JobManager
      - FLINK_PROPERTIES_JOBMANAGER_RPC_ADDRESS=jobmanager
      # Número de slots de tarea que este TaskManager ofrecerá
      - FLINK_PROPERTIES_TASKMANAGER_NUMBER_OF_TASK_SLOTS=1
    volumes:
      # Monta un volumen para persistir los logs del TaskManager
      - ./logs/taskmanager:/opt/flink/log
    depends_on:
      - jobmanager # Asegura que el JobManager se inicie antes que el TaskManager
    networks:
      - flink-network
    # Puedes escalar los TaskManagers ejecutando 'docker-compose up --scale taskmanager=N -d'

networks:
  flink-network:
    driver: bridge # Define una red para que los servicios puedan comunicarse entre sí
