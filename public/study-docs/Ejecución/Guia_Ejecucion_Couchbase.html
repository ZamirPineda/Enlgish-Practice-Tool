Guia_Ejecucion_Couchbase

Explicación

Esta guía le permitirá configurar una instancia básica de Couchbase Server de un solo nodo utilizando Podman (o Docker). La configuración incluye el levantamiento del contenedor del servidor de Couchbase y un script para la inicialización automática del nodo, la configuración de un usuario administrador y la creación de un bucket de datos.

Pasos a seguir:

1. Guardar Archivos: Guarde el contenido de Dockerfile y setup.sh en la misma carpeta en su máquina local.

2. Construir la Imagen: Abra una terminal en la carpeta donde guardó los archivos y construya la imagen de Docker:

    podman build -t couchbase-server-custom .
    # O si usa Docker:
    # docker build -t couchbase-server-custom .

3. Ejecutar el Contenedor: Inicie el contenedor de Couchbase utilizando el comando proporcionado. Este comando lanzará el servidor, mapeará los puertos necesarios y montará el script setup.sh dentro del contenedor en /tmp/setup.sh. También montará un volumen para la persistencia de los datos.

    podman run -d --name couchbase -p 8091:8091 -p 8092:8092 -p 8093:8093 -p 8094:8094 -p 11210:11210 -v couchbase_data:/opt/couchbase/var -v ./setup.sh:/tmp/setup.sh couchbase-server-custom
    # O si usa Docker:
    # docker run -d --name couchbase -p 8091:8091 -p 8092:8092 -p 8093:8093 -p 8094:8094 -p 11210:11210 -v couchbase_data:/opt/couchbase/var -v ./setup.sh:/tmp/setup.sh couchbase-server-custom

4. Ejecutar el Script de Configuración: Una vez que el contenedor esté en ejecución, ejecute el script setup.sh dentro del contenedor para inicializar Couchbase. Es importante esperar unos segundos después de que el contenedor se inicie para que el servidor de Couchbase esté listo.

    podman exec -it couchbase /bin/bash -c "chmod +x /tmp/setup.sh && /tmp/setup.sh"
    # O si usa Docker:
    # docker exec -it couchbase /bin/bash -c "chmod +x /tmp/setup.sh && /tmp/setup.sh"

5. Acceder a la Interfaz de Usuario: Una vez que el script de configuración haya terminado, podrá acceder a la Consola Web de Couchbase a través de su navegador web en http://localhost:8091.

Utilice las siguientes credenciales para iniciar sesión:

  • * Usuario: Administrator
  • * Contraseña: password

¡Felicidades! Ha levantado una instancia de Couchbase Server con un bucket llamado test_bucket listo para usar.

Archivos de Configuración

Dockerfile

FROM couchbase/server:7.2.3

# Este Dockerfile simplemente utiliza la imagen oficial de Couchbase Server.
# Para una configuración básica local, es común ejecutar directamente desde la imagen oficial.
# No se suelen necesitar modificaciones personalizadas aquí a menos que se requieran
# extensiones específicas o pre-configuraciones que no puedan realizarse mediante scripts de inicialización.

# Exponer los puertos que los servicios de Couchbase suelen utilizar:
# 8091: Consola Web, API REST
# 8092: Servicio de Analytics
# 8093: Servicio de Consultas (N1QL)
# 8094: Servicio de Búsqueda de Texto Completo (FTS)
# 11210: Servicio de Datos (Key-Value)
EXPOSE 8091 8092 8093 8094 11210

setup.sh

#!/bin/bash

# Script para inicializar un nodo de Couchbase Server.

echo "Esperando que el servidor de Couchbase se inicie..."
until curl -s http://127.0.0.1:8091/pools > /dev/null; do
  sleep 5
done
echo "Servidor de Couchbase iniciado."

# Paso 1: Inicializar el nodo con servicios y cuotas de memoria
echo "Inicializando el nodo de Couchbase..."
/opt/couchbase/bin/couchbase-cli cluster-init -c 127.0.0.1:8091 \
  --cluster-username Administrator \
  --cluster-password password \
  --cluster-port 8091 \
  --services data,index,query,fts,analytics,eventing \
  --cluster-ramsize 512 \
  --cluster-index-ramsize 256 \
  --cluster-fts-ramsize 256 \
  --cluster-analytics-ramsize 1024 \
  --cluster-eventing-ramsize 256 \
  --cluster-config-data-path /opt/couchbase/var/lib/couchbase/data \
  --cluster-config-index-path /opt/couchbase/var/lib/couchbase/data \
  --cluster-config-fts-path /opt/couchbase/var/lib/couchbase/data

if [ $? -eq 0 ]; then
  echo "Nodo de Couchbase inicializado correctamente."
else
  echo "La inicialización del nodo de Couchbase falló o ya está inicializado. Asegurando la configuración de administrador."
  # En caso de que la inicialización falle (ej. ya inicializado), establecemos las credenciales de administrador
  /opt/couchbase/bin/couchbase-cli setting-autofailover -c 127.0.0.1:8091 \
    --username Administrator \
    --password password \
    --set-autofailover-enabled 0
fi

# Paso 2: Crear un bucket de ejemplo
echo "Creando el bucket 'test_bucket'..."
/opt/couchbase/bin/couchbase-cli bucket-create -c 127.0.0.1:8091 \
  --username Administrator \
  --password password \
  --bucket test_bucket \
  --bucket-type couchbase \
  --bucket-ramsize 256 \
  --bucket-replica 0 \
  --enable-flush 1

if [ $? -eq 0 ]; then
  echo "Bucket 'test_bucket' creado correctamente."
else
  echo "La creación del bucket 'test_bucket' falló o ya existe."
fi

echo "Script de configuración de Couchbase finalizado."
