Guia_Ejecucion_Apache ActiveMQ

Explicación

Esta configuración proporciona una instancia básica de Apache ActiveMQ, un popular broker de mensajes de código abierto. Ideal para desarrolladores que necesitan una cola de mensajes ligera para pruebas o entornos de desarrollo.

Pasos a seguir:

1. Crear el Dockerfile: Guarda el contenido proporcionado en un archivo llamado Dockerfile en un directorio vacío.

2. Construir la imagen: Abre tu terminal en el mismo directorio y ejecuta el comando podman build -t my-activemq-image . (o docker build -t my-activemq-image . si usas Docker). Esto creará una imagen personalizada basada en la imagen oficial de ActiveMQ.

3. Ejecutar el contenedor: Una vez que la imagen esté construida, ejecuta el comando podman run (o docker run) proporcionado en runCommands.

Detalles de la configuración:

  • Dockerfile: Utiliza la imagen symptoma/activemq:5.18.3 como base, que ya incluye una instalación funcional de ActiveMQ. Expone los puertos 61616 (para conexiones de clientes como JMS, STOMP, etc.) y 8161 (para la consola web de administración).
  • runCommands: Este comando primero construye la imagen y luego inicia un contenedor en segundo plano (-d) llamado activemq. Mapea el puerto 61616 del host al 61616 del contenedor y el puerto 8161 del host al 8161 del contenedor. Esto permite que los clientes y tu navegador accedan al broker y a la consola.

Acceso:

Una vez que el contenedor esté en ejecución, podrás acceder a la consola web de ActiveMQ en http://localhost:8161/admin. Las credenciales por defecto son admin / admin.

Comandos de Ejecución

podman build -t my-activemq-image . && podman run -d --name activemq -p 61616:61616 -p 8161:8161 my-activemq-image

Archivos de Configuración

Dockerfile

# Usa una imagen base de ActiveMQ.
# Esta imagen (symptoma/activemq) ya contiene Apache ActiveMQ preconfigurado.
# Se utiliza la versión 5.18.3 que es una de las estables más recientes de la serie 5.x.
FROM symptoma/activemq:5.18.3

# Metadata del mantenedor (opcional, para identificar quién mantiene esta capa).
LABEL maintainer="Tu Nombre <tu.email@example.com>"

# Expone los puertos por defecto que usa ActiveMQ:
# 61616: Puerto principal para conexiones de clientes (OpenWire, STOMP, MQTT, AMQP, etc.).
# 8161:  Puerto para la consola web de administración, que permite monitorear y gestionar el broker.
EXPOSE 61616
EXPOSE 8161

# El comando por defecto de la imagen base (symptoma/activemq) ya inicia el servidor ActiveMQ.
# No necesitamos añadir un CMD adicional a menos que queramos sobreescribir ese comportamiento por defecto.
# Por ejemplo, el comando CMD original de esta imagen puede ser similar a:
# CMD ["/opt/activemq/bin/activemq", "console"]

# Si se necesitara añadir configuración personalizada (ej. activemq.xml modificado):
# Podrías copiar tu archivo de configuración aquí, por ejemplo:
# COPY activemq.xml /opt/activemq/conf/activemq.xml

# Para persistencia de datos (mensajes, colas, tópicos) o logs,
# se recomienda montar volúmenes externos. Esto se hace en el comando 'podman run' o 'docker run'.
# Por ejemplo, para los datos y logs de ActiveMQ:
# VOLUME ["/opt/activemq/data", "/opt/activemq/log"]
