Guia_Ejecucion_PostgreSQL

Explicación

Esta guía te permitirá levantar una instancia básica de PostgreSQL usando Docker o Podman. Utilizaremos la imagen oficial de PostgreSQL y configuraremos la base de datos, el usuario y la contraseña mediante variables de entorno. Los datos de la base de datos se persistirán en un volumen, asegurando que no se pierdan al reiniciar el contenedor. Aunque no es estrictamente necesario un Dockerfile personalizado para una configuración básica (se puede usar la imagen oficial directamente), hemos incluido uno mínimo para demostrar la estructura. No se necesitan archivos de soporte adicionales, ya que las variables de entorno son suficientes para la configuración inicial.

Comandos de Ejecución

docker run -d --name my-postgres -p 5432:5432 -e POSTGRES_USER=myuser -e POSTGRES_PASSWORD=mypassword -e POSTGRES_DB=mydb -v pgdata:/var/lib/postgresql/data postgres:latest

Si usas Podman, simplemente reemplaza 'docker' por 'podman':
podman run -d --name my-postgres -p 5432:5432 -e POSTGRES_USER=myuser -e POSTGRES_PASSWORD=mypassword -e POSTGRES_DB=mydb -v pgdata:/var/lib/postgresql/data postgres:latest

Archivos de Configuración

Dockerfile

# Usa la imagen oficial de PostgreSQL como base. Esto asegura que obtendremos
# una instalación de PostgreSQL preconfigurada y lista para usar.
FROM postgres:latest

# Este Dockerfile es mínimo porque la imagen oficial de PostgreSQL
# ya incluye todo lo necesario para una configuración básica.
#
# Opcionalmente, podrías añadir archivos SQL personalizados para inicializar
# tu base de datos con esquemas o datos específicos al iniciar el contenedor.
# Por ejemplo:
# COPY init.sql /docker-entrypoint-initdb.d/
# Cualquier archivo .sql, .sh o .gz en /docker-entrypoint-initdb.d/ será
# ejecutado por la imagen oficial cuando el contenedor se inicie por primera vez.

# EXPOSE 5432 (el puerto 5432 ya está expuesto por la imagen base de PostgreSQL)
