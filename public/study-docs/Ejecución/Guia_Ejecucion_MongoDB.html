Guia_Ejecucion_MongoDB

Explicación

Esta configuración levantará una instancia básica de MongoDB utilizando la imagen oficial. Se persistirán los datos en un volumen nombrado y se configurará un usuario administrador inicial con contraseña. Los pasos son los siguientes:

1. Crea el Dockerfile: Guarda el contenido proporcionado como Dockerfile en tu directorio de trabajo.

2. Construye la imagen: Ejecuta el comando de construcción para crear tu imagen local de MongoDB.

3. Ejecuta el contenedor: Utiliza el comando podman run o docker run para iniciar la instancia de MongoDB. Esto mapeará el puerto 27017 de tu máquina local al puerto 27017 del contenedor y creará un volumen para la persistencia de datos.

Comandos de Ejecución

podman build -t my-mongo-instance . && podman run -d -p 27017:27017 --name mongodb-instance -v mongo-data:/data/db -e MONGO_INITDB_ROOT_USERNAME=admin -e MONGO_INITDB_ROOT_PASSWORD=password my-mongo-instance

# O, si usas Docker:
docker build -t my-mongo-instance . && docker run -d -p 27017:27017 --name mongodb-instance -v mongo-data:/data/db -e MONGO_INITDB_ROOT_USERNAME=admin -e MONGO_INITDB_ROOT_PASSWORD=password my-mongo-instance

Archivos de Configuración

Dockerfile

# Usa la imagen oficial de MongoDB como base
FROM mongo:latest

# El puerto por defecto de MongoDB es 27017. La imagen base ya lo expone.
# EXPOSE 27017

# El ENTRYPOINT y CMD de la imagen base ya se encargan de iniciar el servidor `mongod`.
# No necesitamos modificarlos para una configuración básica.

# Puedes añadir archivos de inicialización de la base de datos aquí si los necesitas.
# Por ejemplo, para ejecutar scripts JavaScript al iniciar el contenedor por primera vez:
# COPY ./init-mongo.js /docker-entrypoint-initdb.d/

# Este Dockerfile es intencionalmente minimalista para demostrar el uso de la imagen oficial
# y permitir configuraciones sencillas a través de variables de entorno, como el usuario
# y contraseña del administrador, que se pasan en el comando `podman run` o `docker run`.
