Guia_Ejecucion_Cosmos DB

Explicación

Azure Cosmos DB es una base de datos distribuida globalmente, NoSQL y relacional, totalmente administrada por Microsoft Azure. Para el desarrollo local, Microsoft proporciona el "Azure Cosmos DB Emulator", que replica la funcionalidad del servicio en la nube en tu máquina local. Esto permite a los desarrolladores construir y probar aplicaciones de Cosmos DB sin incurrir en costos de Azure y sin necesidad de una conexión a internet. Este setup utiliza docker-compose para orquestar el emulador de forma sencilla, exponiendo los puertos necesarios y configurando un volumen persistente para los datos. Puedes acceder al explorador de datos del emulador a través de https://localhost:8081/_explorer/index.html en tu navegador. Ignora cualquier advertencia de certificado, ya que el emulador usa certificados autofirmados. Para Podman, puedes usar podman-compose como reemplazo directo de docker-compose.

Comandos de Ejecución

docker-compose up -d

Archivos de Configuración

docker-compose.yml

version: '3.8'

services:
  cosmosdb-emulator:
    # Utiliza la imagen oficial de Microsoft para el emulador de Cosmos DB en Linux.
    image: mcr.microsoft.com/azure-cosmos-db/linux/azure-cosmos-db-emulator
    container_name: cosmosdb-emulator
    ports:
      - "8081:8081" # Puerto principal de la API SQL (documentos) y el explorador de datos.
      - "10251:10251" # Puerto de la API de MongoDB.
      - "10252:10252" # Puerto de la API de Gremlin (Graph).
      - "10253:10253" # Puerto de la API de Cassandra.
      - "10254:10254" # Puerto de la API de Table (Azure Table Storage compatible).
      - "10255:10255" # Puerto secundario de la API SQL.
    volumes:
      - cosmosdb_data:/cosmos/data # Monta un volumen para la persistencia de los datos del emulador.
    environment:
      # Argumentos opcionales para el emulador. /DisableRateLimiting es útil para desarrollo local.
      - AZURE_COSMOS_EMULATOR_ARGS=/DisableRateLimiting
    # Un "healthcheck" para asegurar que el contenedor está listo y funcional.
    healthcheck:
      test: ["CMD", "curl", "-f", "https://localhost:8081/_explorer/index.html", "--insecure"]
      interval: 30s
      timeout: 10s
      retries: 5
      start_period: 60s

volumes:
  # Definición del volumen persistente para los datos del emulador.
  cosmosdb_data:
    driver: local
