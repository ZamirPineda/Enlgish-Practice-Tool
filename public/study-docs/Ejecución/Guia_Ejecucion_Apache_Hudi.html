Guia_Ejecucion_Apache Hudi

Explicación

Esta guía le permitirá configurar un entorno local básico de Apache Hudi utilizando Spark y MinIO como almacenamiento de objetos, todo orquestado con Docker Compose. Apache Hudi es una plataforma de data lake que facilita la gestión de datos a escala, ofreciendo capacidades de transacciones ACID, upserts, y deletes sobre formatos de archivo como Parquet o ORC.

La configuración incluye:

  • MinIO: Un servicio de almacenamiento de objetos compatible con S3, que actuará como nuestro data lake.
  • Apache Spark: Un motor de procesamiento de datos distribuido, con una imagen de Docker personalizada que incluye las bibliotecas de Hudi necesarias para interactuar con él.

Los pasos a seguir son:

1. Guarde los contenidos proporcionados en los archivos docker-compose.yml, Dockerfile.spark y hudi_example.py en un mismo directorio.

2. Construya la imagen de Spark personalizada y levante los servicios con docker-compose up -d --build.

3. Una vez que los servicios estén en ejecución, ejecute el script de ejemplo de Hudi usando spark-submit dentro del contenedor spark-master.

4. El script hudi_example.py realizará las siguientes operaciones:

  • * Creará un DataFrame de muestra.
  • * Escribirá los datos en una tabla Hudi (hudi_cow_table) en MinIO en modo 'Copy-on-Write' (CoW).
  • * Realizará una operación de 'upsert' (actualizar/insertar) en la tabla.
  • * Leerá los datos de la tabla Hudi para verificar las operaciones.

Una vez finalizado, puede inspeccionar los datos generados en el bucket de MinIO (accesible en http://localhost:9000 con minioadmin/minioadmin).

Comandos de Ejecución

docker-compose up -d --build && docker-compose exec spark-master spark-submit --master spark://spark-master:7077 --driver-memory 2G --executor-memory 2G --executor-cores 1 --conf "spark.serializer=org.apache.spark.serializer.KryoSerializer" --conf "spark.sql.catalog.spark_catalog=org.apache.spark.sql.hudi.catalog.HoodieCatalog" --conf "spark.hadoop.fs.s3a.endpoint=http://minio:9000" --conf "spark.hadoop.fs.s3a.access.key=minioadmin" --conf "spark.hadoop.fs.s3a.secret.key=minioadmin" --conf "spark.hadoop.fs.s3a.path.style.access=true" --conf "spark.hadoop.fs.s3a.impl=org.apache.hadoop.fs.s3a.S3AFileSystem" /opt/spark-apps/hudi_example.py

Archivos de Configuración

Dockerfile.spark

FROM apache/spark:3.3.0

USER root

# Establecer directorio para las JARs de Hudi y S3
ENV HUDI_SPARK_JARS_DIR /opt/spark/jars/hudi
RUN mkdir -p ${HUDI_SPARK_JARS_DIR}

# Descargar las JARs de Apache Hudi (versión 0.13.0 compatible con Spark 3.3.0 y Scala 2.12)
# Hudi Spark Bundle para Hudi en Spark
RUN wget -q https://repo1.maven.org/maven2/org/apache/hudi/hudi-spark-bundle_2.12/0.13.0/hudi-spark-bundle_2.12-0.13.0.jar -P ${HUDI_SPARK_JARS_DIR}

# Descargar las JARs necesarias para la conexión S3a (MinIO)
# hadoop-aws para el conector S3a
RUN wget -q https://repo1.maven.org/maven2/org/apache/hadoop/hadoop-aws/3.3.2/hadoop-aws-3.3.2.jar -P ${HUDI_SPARK_JARS_DIR}
# spark-hadoop-cloud para integración con Hadoop Cloud (S3a)
RUN wget -q https://repo1.maven.org/maven2/org/apache/spark/spark-hadoop-cloud_2.12/3.3.0/spark-hadoop-cloud_2.12-3.3.0.jar -P ${HUDI_SPARK_JARS_DIR}
# aws-java-sdk-bundle para dependencias del SDK de AWS
RUN wget -q https://repo1.maven.org/maven2/com/amazonaws/aws-java-sdk-bundle/1.12.262/aws-java-sdk-bundle-1.12.262.jar -P ${HUDI_SPARK_JARS_DIR}

# Agregar los directorios de JARs al CLASSPATH de Spark
ENV SPARK_DIST_CLASSPATH="${SPARK_DIST_CLASSPATH}:${HUDI_SPARK_JARS_DIR}/*"

# Crear un directorio para las aplicaciones de Spark
RUN mkdir -p /opt/spark-apps
WORKDIR /opt/spark-apps

USER spark

docker-compose.yml

version: '3.8'

services:
  minio:
    image: minio/minio
    hostname: minio
    ports:
      - "9000:9000"
      - "9001:9001"
    volumes:
      - ./minio_data:/data
    environment:
      MINIO_ROOT_USER: minioadmin
      MINIO_ROOT_PASSWORD: minioadmin
      MINIO_BROWSER_REDIRECT_URL: http://localhost:9000
    command: server --console-address ":9001" /data
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:9000/minio/health/live"]
      interval: 30s
      timeout: 20s
      retries: 3

  spark-master:
    build:
      context: .
      dockerfile: Dockerfile.spark
    hostname: spark-master
    command: bin/spark-shell
    environment:
      SPARK_MASTER_PORT: 7077
      SPARK_MASTER_WEBUI_PORT: 8080
      SPARK_DRIVER_HOST: spark-master
      SPARK_LOCAL_IP: spark-master
      MINIO_ACCESS_KEY: minioadmin
      MINIO_SECRET_KEY: minioadmin
    ports:
      - "8080:8080" # Spark Master UI
      - "7077:7077" # Spark Master port
    volumes:
      - ./hudi_example.py:/opt/spark-apps/hudi_example.py
    depends_on:
      minio:
        condition: service_healthy

  spark-worker:
    build:
      context: .
      dockerfile: Dockerfile.spark
    hostname: spark-worker
    command: bin/spark-worker spark://spark-master:7077
    environment:
      SPARK_MASTER_URL: spark://spark-master:7077
      SPARK_WORKER_WEBUI_PORT: 8081
      SPARK_WORKER_CORES: 1
      SPARK_WORKER_MEMORY: 2G
      SPARK_DRIVER_HOST: spark-worker
      SPARK_LOCAL_IP: spark-worker
      MINIO_ACCESS_KEY: minioadmin
      MINIO_SECRET_KEY: minioadmin
    ports:
      - "8081:8081" # Spark Worker UI
    depends_on:
      spark-master:
        condition: service_started

hudi_example.py

import sys
from pyspark.sql import SparkSession
from pyspark.sql.functions import lit
import time

# Configuración de Spark para Hudi con MinIO
# Las configuraciones s3a.endpoint, s3a.access.key, s3a.secret.key
# y s3a.path.style.access ya están configuradas en el comando spark-submit
# o en el entorno del contenedor, por lo que no es estrictamente necesario duplicarlas aquí,
# pero se incluyen para mayor claridad y auto-contención si se ejecuta de otra manera.

spark = SparkSession.builder \
    .appName("Hudi MinIO Example") \
    .config("spark.serializer", "org.apache.spark.serializer.KryoSerializer") \
    .config("spark.sql.catalog.spark_catalog", "org.apache.spark.sql.hudi.catalog.HoodieCatalog") \
    .config("spark.hadoop.fs.s3a.endpoint", "http://minio:9000") \
    .config("spark.hadoop.fs.s3a.access.key", "minioadmin") \
    .config("spark.hadoop.fs.s3a.secret.key", "minioadmin") \
    .config("spark.hadoop.fs.s3a.path.style.access", "true") \
    .config("spark.hadoop.fs.s3a.impl", "org.apache.hadoop.fs.s3a.S3AFileSystem") \
    .getOrCreate()

spark.sparkContext.setLogLevel("WARN")

print("SparkSession creada exitosamente.")

# Directorio base para la tabla Hudi en MinIO
HUDI_BASE_PATH = "s3a://hudi-bucket/hudi_cow_table"

# Opciones comunes para escribir en Hudi
HUDI_COMMON_OPTIONS = {
    'hoodie.table.name': 'hudi_cow_table',
    'hoodie.datasource.write.recordkey.field': 'uuid',
    'hoodie.datasource.write.partitionpath.field': 'timestamp_date',
    'hoodie.datasource.write.table.type': 'COPY_ON_WRITE',
    'hoodie.datasource.write.operation': 'upsert',
    'hoodie.datasource.write.precombine.field': 'timestamp',
    'hoodie.cleaner.commits.retained': '2' # Retener solo las últimas 2 commits para demostración
}

def write_data(data_df, write_mode='append', operation='upsert'):
    print(f"\nEscribiendo datos a Hudi (modo: {write_mode}, operación: {operation})...")
    data_df.write.format("hudi") \
        .options(**HUDI_COMMON_OPTIONS) \
        .option('hoodie.datasource.write.operation', operation) \
        .mode(write_mode) \
        .save(HUDI_BASE_PATH)
    print("Escritura completada.")

def read_data(query_type='snapshot'):
    print(f"\nLeyendo datos de Hudi (tipo de consulta: {query_type})...")
    hudi_read_options = {
        'hoodie.datasource.query.type': query_type
    }
    df = spark.read.format("hudi") \
        .options(**hudi_read_options) \
        .load(HUDI_BASE_PATH)
    df.show(truncate=False)
    print(f"Total de registros leídos: {df.count()}")
    return df

# 1. Escritura inicial de datos
print("--- Paso 1: Escritura inicial de datos ---")
initial_data = [
    {"uuid": "1", "name": "Alice", "age": 30, "city": "New York", "timestamp": time.time(), "timestamp_date": "2023-01-01"},
    {"uuid": "2", "name": "Bob", "age": 24, "city": "Los Angeles", "timestamp": time.time(), "timestamp_date": "2023-01-01"},
    {"uuid": "3", "name": "Charlie", "age": 35, "city": "Chicago", "timestamp": time.time(), "timestamp_date": "2023-01-02"}
]
initial_df = spark.createDataFrame(initial_data)
write_data(initial_df, write_mode='overwrite', operation='insert') # Usamos 'overwrite' la primera vez para asegurar un estado limpio
read_data().filter(lit("uuid").isin("1","2","3")).sort("uuid").show(truncate=False)

# 2. Realizar un Upsert (actualizar Bob, insertar David)
print("\n--- Paso 2: Realizar un Upsert ---")
upsert_data = [
    {"uuid": "2", "name": "Robert", "age": 25, "city": "San Francisco", "timestamp": time.time(), "timestamp_date": "2023-01-01"}, # Actualizar Bob
    {"uuid": "4", "name": "David", "age": 29, "city": "Houston", "timestamp": time.time(), "timestamp_date": "2023-01-03"} # Insertar David
]
upsert_df = spark.createDataFrame(upsert_data)
write_data(upsert_df, write_mode='append', operation='upsert')

# 3. Leer datos después del upsert
print("\n--- Paso 3: Leer datos después del Upsert ---")
read_data().sort("uuid").show(truncate=False)

# 4. Eliminar un registro (ej. Charlie)
print("\n--- Paso 4: Eliminar un registro (Charlie) ---")
delete_data = [
    {"uuid": "3", "name": "Charlie", "age": 35, "city": "Chicago", "timestamp": time.time(), "timestamp_date": "2023-01-02"} # Solo necesitamos el record key y partition path
]
delete_df = spark.createDataFrame(delete_data)
write_data(delete_df, write_mode='append', operation='delete')

# 5. Leer datos después de la eliminación
print("\n--- Paso 5: Leer datos después de la eliminación ---")
read_data().sort("uuid").show(truncate=False)

print("\nEjemplo de Apache Hudi completado exitosamente.")

spark.stop()
