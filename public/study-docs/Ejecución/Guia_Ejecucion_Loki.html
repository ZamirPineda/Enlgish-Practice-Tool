Guia_Ejecucion_Loki

Explicación

Esta guía te ayudará a levantar una instancia básica de Loki, Promtail y Grafana localmente usando Docker Compose.\n\n Loki: Es un sistema de agregación de logs diseñado para ser eficiente y escalable. Almacena logs de una manera similar a como Prometheus almacena métricas, indexando solo metadatos (etiquetas) en lugar del contenido completo del log.\n Promtail: Es el agente de Loki, encargado de descubrir, recolectar y enviar logs de las aplicaciones a Loki. En esta configuración, Promtail estará configurado para recolectar logs de otros contenedores Docker en el mismo host.\n* Grafana: Es una plataforma de visualización y análisis de código abierto. La usaremos para consultar y visualizar los logs almacenados en Loki a través de su interfaz de usuario.\n\nEl docker-compose.yml define los tres servicios, sus configuraciones y cómo se conectan entre sí. Los archivos de configuración de Loki, Promtail y Grafana se montan como volúmenes para una fácil personalización.\n\nPasos:\n1. Guarda los archivos docker-compose.yml, loki-config.yml, promtail-config.yml y grafana-datasource.yml en el mismo directorio.\n2. Ejecuta el comando docker-compose up -d para iniciar los contenedores.\n3. Accede a Grafana en http://localhost:3000. El usuario y la contraseña por defecto son admin/admin. Se te pedirá que cambies la contraseña al iniciar sesión por primera vez.\n4. Una vez en Grafana, la fuente de datos de Loki ya debería estar configurada. Navega a "Explore" y selecciona "Loki" como tu fuente de datos.\n5. Puedes usar la barra de consulta de LogQL (lenguaje de consulta de Loki) para buscar logs. Por ejemplo, {job="docker"} mostrará todos los logs recolectados por Promtail.

Comandos de Ejecución

docker-compose up -d

Archivos de Configuración

docker-compose.yml

version: "3.8"\n\nnetworks:\n  loki-grafana:\n\nservices:\n  loki:\n    image: grafana/loki:2.9.0\n    container_name: loki\n    ports:\n      - "3100:3100"\n    command: -config.file=/etc/loki/config.yml\n    volumes:\n      - ./loki-config.yml:/etc/loki/config.yml\n      - loki-data:/loki\n    networks:\n      - loki-grafana\n    restart: unless-stopped\n\n  promtail:\n    image: grafana/promtail:2.9.0\n    container_name: promtail\n    command: -config.file=/etc/promtail/config.yml\n    volumes:\n      - ./promtail-config.yml:/etc/promtail/config.yml\n      - /var/log:/var/log\n      - /var/lib/docker/containers:/var/lib/docker/containers:ro\n      - /var/run/docker.sock:/var/run/docker.sock:ro\n    networks:\n      - loki-grafana\n    restart: unless-stopped\n\n  grafana:\n    image: grafana/grafana:10.2.3\n    container_name: grafana\n    ports:\n      - "3000:3000"\n    volumes:\n      - grafana-data:/var/lib/grafana\n      - ./grafana-datasource.yml:/etc/grafana/provisioning/datasources/loki-datasource.yml\n    networks:\n      - loki-grafana\n    restart: unless-stopped\n\nvolumes:\n  loki-data:\n  grafana-data:
