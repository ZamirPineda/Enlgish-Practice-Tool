Guia_Ejecucion_YugabyteDB

Explicación

Esta guía le permitirá configurar una instancia local básica de YugabyteDB utilizando docker-compose. YugabyteDB es una base de datos SQL distribuida de código abierto, compatible con PostgreSQL y Cassandra, diseñada para cargas de trabajo de alto rendimiento y escalabilidad horizontal. Esta configuración lanzará un clúster de 3 nodos máster y 3 nodos de servidor de tablas (tservers), proporcionando una configuración básica de alta disponibilidad y tolerancia a fallos. Los datos se persistirán utilizando volúmenes de Docker.

Componentes del Clúster:

  • 3 YB-Master nodes: Gestionan los metadatos del clúster y la coordinación. Corren en los puertos RPC 7100 y la UI en el puerto 7000 (solo para yb-master-1 expuesto al host).
  • 3 YB-TServer nodes: Almacenan y sirven los datos. Corren en los puertos RPC 9100, la UI en el puerto 9000 (solo para yb-tserver-1 expuesto al host), la API PostgreSQL en 5433 y la API Cassandra en 9042 (ambas solo para yb-tserver-1 expuestas al host).

Pasos para Iniciar:

1. Asegúrese de tener Docker o Podman y Docker Compose (o Podman Compose) instalados en su sistema.

2. Cree un directorio para su proyecto, por ejemplo, yugabytedb-local.

3. Dentro de este directorio, cree un archivo llamado docker-compose.yml con el contenido proporcionado en supportFiles.

4. Abra una terminal en el directorio yugabytedb-local.

5. Ejecute el comando docker-compose up -d para construir y lanzar el clúster.

Verificación:

  • Una vez que los contenedores estén en ejecución, puede acceder a la UI del máster en http://localhost:7000.
  • Puede conectar a la base de datos PostgreSQL en localhost:5433 con el usuario yugabyte y sin contraseña. Por ejemplo, usando psql:

psql -h localhost -p 5433 -U yugabyte

  • Puede conectar a la API de Cassandra en localhost:9042.

Para detener y limpiar el clúster (incluyendo los datos), use docker-compose down -v.

Comandos de Ejecución

docker-compose up -d

Archivos de Configuración

docker-compose.yml

version: '3.8'
services:
  yb-master-1:
    image: yugabytedb/yugabyte:2.20.1.0-b2
    container_name: yb-master-1
    command: ["/home/yugabyte/bin/yb-master", "--fs_data_dirs", "/mnt/disk0", "--rpc_bind_addresses", "yb-master-1:7100", "--master_addresses", "yb-master-1:7100,yb-master-2:7100,yb-master-3:7100", "--replication_factor=3"]
    ports:
      - "7000:7000" # Master UI
    volumes:
      - yb-master-1-data:/mnt/disk0
    networks:
      - yb-network

  yb-master-2:
    image: yugabytedb/yugabyte:2.20.1.0-b2
    container_name: yb-master-2
    command: ["/home/yugabyte/bin/yb-master", "--fs_data_dirs", "/mnt/disk0", "--rpc_bind_addresses", "yb-master-2:7100", "--master_addresses", "yb-master-1:7100,yb-master-2:7100,yb-master-3:7100", "--replication_factor=3"]
    volumes:
      - yb-master-2-data:/mnt/disk0
    networks:
      - yb-network

  yb-master-3:
    image: yugabytedb/yugabyte:2.20.1.0-b2
    container_name: yb-master-3
    command: ["/home/yugabyte/bin/yb-master", "--fs_data_dirs", "/mnt/disk0", "--rpc_bind_addresses", "yb-master-3:7100", "--master_addresses", "yb-master-1:7100,yb-master-2:7100,yb-master-3:7100", "--replication_factor=3"]
    volumes:
      - yb-master-3-data:/mnt/disk0
    networks:
      - yb-network

  yb-tserver-1:
    image: yugabytedb/yugabyte:2.20.1.0-b2
    container_name: yb-tserver-1
    command: ["/home/yugabyte/bin/yb-tserver", "--fs_data_dirs", "/mnt/disk0", "--rpc_bind_addresses", "yb-tserver-1:9100", "--tserver_master_addrs", "yb-master-1:7100,yb-master-2:7100,yb-master-3:7100"]
    ports:
      - "9000:9000" # TServer UI
      - "5433:5433" # YSQL API (PostgreSQL compatible)
      - "9042:9042" # YCQL API (Cassandra compatible)
    volumes:
      - yb-tserver-1-data:/mnt/disk0
    depends_on:
      - yb-master-1
      - yb-master-2
      - yb-master-3
    networks:
      - yb-network

  yb-tserver-2:
    image: yugabytedb/yugabyte:2.20.1.0-b2
    container_name: yb-tserver-2
    command: ["/home/yugabyte/bin/yb-tserver", "--fs_data_dirs", "/mnt/disk0", "--rpc_bind_addresses", "yb-tserver-2:9100", "--tserver_master_addrs", "yb-master-1:7100,yb-master-2:7100,yb-master-3:7100"]
    volumes:
      - yb-tserver-2-data:/mnt/disk0
    depends_on:
      - yb-master-1
      - yb-master-2
      - yb-master-3
    networks:
      - yb-network

  yb-tserver-3:
    image: yugabytedb/yugabyte:2.20.1.0-b2
    container_name: yb-tserver-3
    command: ["/home/yugabyte/bin/yb-tserver", "--fs_data_dirs", "/mnt/disk0", "--rpc_bind_addresses", "yb-tserver-3:9100", "--tserver_master_addrs", "yb-master-1:7100,yb-master-2:7100,yb-master-3:7100"]
    volumes:
      - yb-tserver-3-data:/mnt/disk0
    depends_on:
      - yb-master-1
      - yb-master-2
      - yb-master-3
    networks:
      - yb-network

networks:
  yb-network:
    driver: bridge

volumes:
  yb-master-1-data:
  yb-master-2-data:
  yb-master-3-data:
  yb-tserver-1-data:
  yb-tserver-2-data:
  yb-tserver-3-data:
