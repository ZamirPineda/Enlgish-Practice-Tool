# AGENT BEHAVIOR & PROJECT GUIDELINES

## 1. Environment & Shell

- **OS:** Windows.
- **Shell:** You MUST use `cmd` (Command Prompt).
- **Forbidden:** Do NOT use `bash`, `powershell`, `ls`, `grep`, or `sudo`.
- **Path Separators:** Use backslashes `\` or handle paths in a cross-platform node compatible way.

## 2. Package Manager

- **Strictly use:** `pnpm`.
- **Forbidden:** `npm`, `yarn`, `bun`.
- **Lockfile:** Always respect `pnpm-lock.yaml`.
- If you need to install a dependency, use `pnpm add`.
- If you need to run a script, use `pnpm run <script>`.

## 3. Definition of Done (DoD)

Before you confirm a task is complete or present code to the user, you MUST:

1. Lint the code if a linter is configured.
2. **MANDATORY:** Run `pnpm run test:ci` to verify your changes did not break anything.
3. If `test:ci` fails, you must attempt to fix the error yourself before asking the user.
4. Only when tests pass is the task considered "Complete".

## 4. Coding Style

- Keep code clean, modular, and typed (if TypeScript).
- Follow the existing project architecture.
