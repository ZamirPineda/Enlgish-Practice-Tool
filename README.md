# English Practice Tool

A static web application for practicing English vocabulary, studying decks, and reviewing personal scripts.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`

2. Run the app:
   `npm run dev`

## Deployment

This app is configured for GitHub Pages with the base path `/Enlgish-Practice-Tool/`.
Run `npm run build` to generate the static assets in `dist/`.
